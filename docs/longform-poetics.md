# 长篇叙事中的真、善与美

“真”包括世界前后一致，也包括人物有限、犹疑、有自我解释却未必完全了解自己。规则保证钱和时间不能凭空出现，文学表达呈现同一处境对不同人意味着什么。

“善”首先需要行动空间：愿意解释而不是默认对方应该懂；把额外劳动说清、付报酬；承认自己的便利可能来自别人的负担；给予帮助而不索取关系；在能力有限时守住边界。人物可以做不到，也可以迟一步才明白。程序不发道德积分，不保证好意得到回报，不安排某一类人物承担全部牺牲。

“美”要有可工作的形式层：选择值得停留的场景，用人物自己的语气说话，让一个普通物件在不同处境中获得变化的意味，用重复与变化形成呼应，用克制保留复杂感受。它不等于给每段加抒情句，也不等于苦难被一句漂亮话抹平。

## 允许创作的空间

1. 硬事实：行动结果、钱款、期限、权限、位置、承诺、知识来源、明确表达的边界。必须服从世界记录。
2. 场景表达：在已知地点和时间范围内选择感官焦点、环境纹理、非决定性的动作细节、对话节奏、停顿与比喻。只要不新增改变后续世界的事实，就不要求每个词都在日志里出现。
3. 解释：人物的理解可以片面，叙述不能把它偷偷变成全知判决。有限视角不直接断言其他人物的隐藏动机。
4. 持续细节：反复出现的物件、称呼、习惯和共同记忆，一旦用于后章便有来源与连续性记录。装饰性细节若将改变人物选择，须先通过世界行动建立，不能由作家追认。

例如，甲人物给乙人物承担两小时工作，必须有请求/同意/时间与产物记录；写这两小时里灯光如何落在纸边，可以是文学表达。灯光不能成为虚构停电、搬家或被目击的证据。关心可以出现在说话和行动的方式里，但写作不能替角色承诺无期限照顾。

## 张力不只来自打击

两个合理但不能同时满足的目标、好意与对方真正需要之间的差异、解释过晚、尚未兑现的安排、逐渐学会的合作，都能产生张力。外部事件在运行前固定，不按“缺戏”临时制造灾难。复杂性来自各自有限而真实的选择相遇。

## 审阅的两条线

事实审阅核查矛盾、信息越界与偷偷新增的决定性情节。文学审阅评价具体段落怎样工作：声音是否区分，是否只有总结，哪里解释过多，善意是否有实际承载，是否美化了不平等或抹掉拒绝，意象是否贴近日常。

两条线分别保存问题与修改版本；文学审阅可以要求重排场景、删掉口号、把抽象评价落回既有行动，不能为追求感动改历史。模型自评不是文学质量的最终证明。开发者抽查属于验证，不成为每轮运行的必要步骤。
