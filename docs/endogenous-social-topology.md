# Endogenous social topology

The previous 32 x 160 scouting run produced pressure histories but too little
social entanglement. This branch changes the causal unit.

A world becomes interesting only when one person's earlier choice changes
another person's later feasible set.

## Authority chain

Macro conditions
→ institution/family/city constraints
→ shared scarce resources and institutional memory
→ actor-specific feasible options
→ bounded character choice
→ micro-world consequence
→ reputation/network transmission
→ later feasible options

## Hard rule

No downstream effect may appear without a causal path.

Every important state change records:
- effective date
- actor/target
- causes
- resource or state changed
- whether the effect is reversible

## Shared scarcity

Initial examples:
- advisor attention
- recommendation slots
- bridge funding
- transition housing
- paid research hours

These are deliberately concrete. If Lin takes the only transition-housing slot,
Chen can no longer choose that option unless capacity changes or Lin releases it.

## Institutional memory

Organizations may remember prior support, reliability, refusals, failures,
successful rescue work, and policy exceptions. Memory changes later decisions
or eligibility only through explicit rules.

## Reputation transmission

Reputation is domain-specific and observer-specific. It cannot become a global
moral score.

## Entry and exit

Graduation, job changes, relocation, family formation, unemployment, and
organizational entry/exit must be explicit state transitions. An inactive actor
cannot silently keep consuming capacity.
