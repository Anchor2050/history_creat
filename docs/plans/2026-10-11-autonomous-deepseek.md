# DeepSeek 独立运行补充设计

用户要求：开发助手退出后，推演、反思、正文、审阅、修订与后续轮次均只依赖本地程序和 DeepSeek；GPT 人工读稿不作为必要运行门槛。

采用有界状态机：行动 → 逐人物反思 → 叙事规划 → 正文 → 整体审阅 → 逐句审阅 → 按问题修订（默认最多两次）→ 下一轮。程序硬规则负责状态合法性，DeepSeek 负责语义判断；模型通过仅标记 model_review_passed，不宣称客观正确。

每个阶段保存进度；API 错误有限次重试，同一进程共用调用总上限。预算耗尽保存现场，不偷偷换模型。恢复从未完成阶段继续，已有行动和已完成的审阅不重复执行。失败稿与各版审阅均保留。每轮写独立稿件目录；总运行报告列出行动停滞、拒绝、草稿状态和用量。

入口 narrative.autorun：场景、输出、轮数、每轮行动数、总调用上限、修订次数、恢复开关。首次运行后可以关闭 Codex；需保持运行该命令的 Python 进程。无需 GPT API、Jev、人工确认或桌面自动化。

验收：自动修订测试、修订限额、阶段恢复不重做、整体预算、纯 DeepSeek 真实多轮运行。保留旧命令兼容。后续长篇质量、规模化仿真仍单独评估。
