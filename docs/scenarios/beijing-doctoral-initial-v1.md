# 北京博士生活：初始设定与推演测试规格 V1

状态：设定草案，供后续实现与用户修订；不是现有 narrative.run 可直接加载的场景。不推进剧情，不安排结局。

## 1. 创作约束与测试对象

用户确定：北京；两名来自三线城市的单身女博士同住宿舍。28 岁者好看但恋爱中不主动；31 岁者忙于毕业和兼职。后者的师弟已去另一所学校读博，目前喜欢并追求她；她因毕业压力、过于熟悉等原因婉拒。

补充设定全部虚构。时间为 2026 年 3 月 2 日，首阶段到 4 月 12 日；毕业与搬离宿舍的更远期限继续保存在世界状态中。甲校、乙校、项目公司均为虚构机构。金额、时数、培养要求和程序都是本次实验参数，不代表北京价格统计、真实校规或全国政策。“三线城市”用于交代两位主角的成长背景，不承担性格或能力解释。

核心问题：当钱、时间、资格、信息和关系不能同时兼顾时，不同人物怎样选择；一次选择怎样改变后续的合作、信任和可选路径。

禁止用三角恋、突发重病、导师性骚扰、秘密富豪、重大事故等强刺激替代既有矛盾。禁止把漂亮、年龄、性别设成决定性格、能力或恋爱结果的数值。没有预设的升华、反派、配对或成功结局。

### 主角的家庭与生活基础

- 林静来自安徽一座地级市。父母为普通职工与中学教师，家里有自住房，没有北京住房。家中可提供每月 1200 元支持，但更希望她获得稳定、离家不太远的工作。她不急于为下一笔生活费接项目，却并不拥有任意留京的资本。
- 陈岚来自河南一座地级市。父亲经营小型维修服务，母亲做零售工作，收入有波动；家里有住房，没有能力持续支付她在北京毕业后的市场租金。她自愿每月给家里 1000 元，父母不知道她的全部余额。没有突发疾病或秘密债务。
- 许航来自山东普通职工家庭，日常主要靠自己的博士资助；父母不是他追求陈岚的资助方。他的博士方向与旧组有方法交集，但新项目不是陈岚论文的附属物。
- 林静与陈岚同住甲校一间双人博士宿舍约两年。熟悉作息与大致压力，关系亲近，但不共享账户、聊天记录、完整家庭账目或他人的私密告白。

## 3. 三个组织与权力流向

1. **甲校社会研究学院**：包含两个课题组、研究生事务岗位和宿舍使用资格。学院规则不是导师一句话；课题组任务、导师意见、程序核验、外审和学位委员会是不同环节。
2. **乙校城市计算研究所**：许航新的学术归属。新导师、研究计划与数据授权独立于甲校。跨校合作需要征得相关方同意，不能靠旧关系自动取得资料。
3. **明衡研究服务公司**：项目经理在客户验收、公司现金和外包研究劳动之间协调。它不控制博士资格；学校也不保证陈岚一定有兼职收入。

宿舍是共同生活单元，不是第三个具有审批权的组织。亲密、声望、人情会影响谁愿意开口和合作，不等于正式许可。父母、外审专家、客户采购部门作为有记录的外部主体；首阶段不为他们生成完整人物回合，也不让他们凭空做改变主线的私人决定。

权力必须落实到对象：谁能签哪份材料、谁能读哪份数据、谁能排哪段时间、谁能决定哪笔支出；“导师有权”“社会压力大”不能代替具体权限。

可分配时间已扣除基本生活、必修安排与固定事务。三个数字用于初始化，不是对性别、年龄或能力的判断。每人的日程另有空间保留休息与交往；不能把少睡觉设成无成本的时间生产。

陈岚有上一份已验收项目的应收款 3200 元，预计 3 月 13 日到账，但未到账前不可支出。新一期基础交付报价 6800 元，估计需 40 小时，3 月 23 日交付；验收后 14 天付款。追加需求需重新报价与接受，不能无条件合并进原任务。她尚未接受新一期，拒绝也不会自动失去旧款。

公司本项目初始可用现金 19000 元，包含对应的已验收应付款；每笔付款双边记账。学校资助、家庭支持、客户回款都有明确外部资金来源与时间。角色不能通过一句“找个项目”创造收入。

与本次故事有关的每周可分配事务时间：吴澄 6 小时、沈雁 4 小时、顾维 6 小时、赵珂 10 小时、孙洁 8 小时。导师可约的一对一讨论每周分别最多 2、2、3 个一小时时段；时段预约同样占用其上述时间。吴澄本项目尚可分配助研预算 6000 元；沈雁的 2400 元助研岗位为独立专项，不能挪作其他任务的无限补贴。这些余额和预约都需记录，不能因角色有职位就随时有钱有空。

其他稀缺资源：导师可约讨论时段、助研岗位名额、可授权的数据、完整的材料版本、推荐意愿、宿舍居住期限，以及当事人的注意力。关系不汇总成“好感度”；分别记录守信、专业可信度、合作负担和明确表达过的边界。

- 导师目前知道她做兼职，不知道全部接单量。她认为导师通常会在最后几天回复；这是旧经验形成的判断，不是世界保证。

- 她的外貌只影响有依据的互动印象，不生成自动录用、爱慕或资源优待。她有自己的研究与生活线，绝不默认喜欢许航。

### 许航

- 新组的复现任务已经定位一处数据版本不一致，需要约 16 小时核查，3 月 20 日组会汇报；结论可以是找到原因，也可以是明确报告尚无法复现。
- 想提出自己的小课题，目前尚无被导师接受的完整方案。
- 陈岚以前帮他梳理过硕士论文结构，他也维护过旧项目代码。这些是互助历史，不是欠债清单。

- 初始仍有喜欢与失落，但知道不存在对方承诺。之后是否减少联系、保留普通合作或建立更清晰距离，由实际互动决定。重复邀约、未经同意的到访、代为安排私人事务不进入默认可执行菜单；任何关系变化必须来自双方新的明确表达，不能由叙述者宣布。

初始没有已经发生的“客户突然加需求”或“导师临时卡人”。可设定的外部扰动单独存入事件表，例如付款批次晚 7 天或讨论时段冲突；在运行前抽样固定，同一对照组使用相同事件表。程序不得因为故事平淡临时追加打击，也不能为推动恋爱解除压力。

时代通过具体组织方式出现：项目制劳动与分批付款、可复核的数据工作、学历资格和岗位资格的分离、跨校流动、异地家庭支持、毕业后的住房转换。涉及 AI 辅助代码或写作时，必须记录使用与人工复核范围；这是虚构项目的质量要求，不冒充统一政策。人物可以不用 AI，不凭工具使用判断其先进或落后。

## 7. 行动菜单与后果

每个行动要有对象、时间成本、前置条件、产物与可见对象。以下是行动族，不是编好的事件轨迹。

| 行动族 | 示例 | 必要约束与后果 |
|---|---|---|
| 研究与写作 | 复核表格、补访、写讨论、复现实验 | 扣日程时间，产出可检查的材料版本；工作失败也要保留发现，不自动涨“论文分” |
| 提交与反馈 | 预约导师、送材料、评阅、退回修改、确认提交 | 权限分层，需对方时段或响应；退回须列缺项或实质问题，不能用一句“权力”代替原因 |
| 劳动协商 | 接受或拒绝报价、谈范围、申请延期、报价追加工作 | 写成双方可见承诺；新义务需当事人接受，时间和报酬可以谈不成 |
| 分工与资源配置 | 导师重新分工、分配助研费、申请数据授权 | 有权者只能处分自己的资源；不允许私转受限数据、默认学生无限接活 |
| 结算 | 提交交付、验收、付款、说明延迟 | 按合同阶段与账户记账；一次对话不能让款项凭空到账 |
| 求职准备 | 修改材料、了解岗位、请求推荐、投递 | 推荐不等于录用；投递不等于岗位存在；岗位资格、回信与选择另存 |
| 日常协商 | 分担采购、约安静时段、请舍友帮一次忙、拒绝帮忙 | 区分一次请求与持续义务；付出有具体成本，拒绝不会自动被判“自私” |
| 关系沟通 | 明确邀请、接受/拒绝、说明边界、暂停联系 | 同意按对象和事项分别记录；学术帮助、友谊和恋爱互不替代 |
| 信息行动 | 询问、解释、转述、保留不愿说的信息 | 记录来源与接收者；不知道别人余额、动机、私聊；可误解，但不直接读取真相 |
| 计划调整与恢复 | 缩小任务、推迟非紧急工作、安排休息、主动求助 | 改变后续承诺和可用时间；反思必须引用已经历事件，不自动重写他人状态 |

## 8. 硬规则与软判断

硬规则：账户守恒；同一时段不能重复占用；权限不能越级；未完成条件不能提交为完成；拒绝与授权边界持续有效；信息必须有传播路径；已发生的事件不能被写作改掉。

软判断：人物为何接受任务、是否愿意解释、怎样权衡风险、对别人是否失望。由 DeepSeek 基于局部视图提出；不以“最理性”“最有戏”评分强迫人物。程序只阻止硬约束违背，允许可解释的拖延、误判和机会流失。

论文质量采用材料与反馈记录，不能由钱、恋爱状态或简单工时总数直接决定。外审结果需要独立评阅输入；第一阶段不运行到学位终点，也不提前宣布陈岚毕业或失败。

持续人物状态包含：当前目标及优先次序、未来两周计划、已承诺事项、已知信息及来源、尚不确定的判断、分领域信任、边界、反思证据。稳定倾向允许在经历后缓慢修正，但不能一次谈话就换人格。

## 9. 约 50 次决策如何运行

- 一轮为一个日历周。8 名人物各获得一次主要决策机会，6 周共 48 次；第 3、6 周各保留一次对已到达重要通知的响应机会，共 50 次。额外机会按通知与资格规则选择，不为某个恋爱结果指定对象；没有合适通知则记录空缺，不制造事件凑数。
- 一次主要决策可安排一组明确的工作时段并提出最多一项对他人的请求。回复、材料到达、支付与已排工作的完成由事件队列处理；需要人物改变承诺时，留待响应机会或下一轮，不由程序替其答应。
- 每周决定依据周初已知状态提出，随后按真实可安排时间执行；不能让固定排在前面的导师凭顺序知道学生尚未提交的决定。跨周任务继续占用后续时间，失约保留记录。
- 提议重试上限、总 API 调用上限和 token 上限独立配置。50 是人物决策机会数，不是 API 调用数，也不是 50 天。有效、被拒、未行动、等待均分别记录。
- 初次只写每周一章或每两周一章，沿用读者已知信息和未解决线索。生成稿不反向制造角色的新经历。各人物的第一人称必须有明确场景标识。

## 10. 为测试上一阶段目标而设的对照

所有对照保持同一外部事件表；模型仍可能有随机差异，一条分支不构成因果证明。先验证运行，再用重复样本比较。

| 对照 | 只改变什么 | 要检查什么，不预设什么 |
|---|---|---|
| 基线 | 上述初值 | 能否形成跨周的计划、后果、章节和人物差异 |
| 现金缓冲 | 陈岚初始现金增加 30000，其他不变 | 接单、争取时间和拒绝工作的选择是否变化；不能因此自动接受许航 |
| 任务分配制度 | 甲校新增明确规则：额外项目劳动需学生确认，并占用已公布的有偿工时预算 | 在导师性格不变时，任务、协商与毕业时间是否变化；不要求导师立刻变成好人或坏人 |
| 表达策略 | 只互换两位舍友“遇到冲突先解释还是先自行消化”的倾向，不换能力、身份、账本或恋爱边界 | 行动与沟通是否受性格影响；不要求每个分支结局必然不同 |
| 感情线消融 | 许航初始没有追求，只保留旧同门合作 | 学业、兼职、住房与友谊是否仍能独立推进；故事不能全靠追求者供给事件 |

验收证据：重大资源变动有账本和授权；每次改计划能指向经历；人物行动前后可见信息可回溯；关系变化与对应行为有依据；后续章节不重述已写完的事件、不泄露角色未知信息。记录重复率、长期未处理事项、跨周后果和章节事实问题，不把指标合成为“文学质量分”。

对照中没有出现差异时，应报告差异不足并检查时间跨度、约束强度与角色决策机制；不能补写一个不同结局冒充测试成功。

## 11. 与现有程序的接口和缺口

现有可复用：私有视图、来源化主张、组织权限、资源申请与分配、承诺后果、因果记录、DeepSeek 自动审阅修订、预算停止和恢复。

必须先实现再运行：日历与跨周事件队列、同周信息冻结、个人时间账本、可检查的论文/项目产物及多级审批、持续计划与优先次序、分领域关系与同意边界、连续章节的读者记忆、固定外部事件表与对照分支。现有单动作推进一 tick 的机制不能直接代表这一生活世界。

本文件与配套 JSON 只冻结初值与实验设计，不触发模型调用，不预写第一周，不声称这些扩展已经实现。首阶段先用离线制度与时间测试验证，再让纯 DeepSeek 自主运行基线；是否扩大到所有对照，应依据实测费用和结果决定。
