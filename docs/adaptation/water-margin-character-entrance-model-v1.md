# 《水浒传》式人物出场模型 v1

状态：adaptation-only，服务于《不同的稳定》的小说化改写。历史账本不回写。

## 当前问题

现有开篇人物研究很充分，但小说性不足：人物多、名字密、背景解释多、场景像履历切片。读者在记信息，尚未真正“看见一个人进场”。

本轮重置一个核心原则：

> 先有事，再出人；人在事里被看见。

参考《水浒传》的不是章回腔、古典句式或英雄类型，而是人物出场机制：人物往往先被一个具体场面召入故事，随后通过行动、语言、他人反应、名声/位置和一个局部冲突迅速立起来。背景不是一次性交代，而是随着事情推进逐步补出。

## 一、第一次出场必须是一场戏

首次正式出场禁止人物简介式段落。一个核心人物第一次进入读者视野，至少具备：

1. 一个正在发生的外部事件；
2. 一个清楚的空间；
3. 一个必须立刻处理的问题；
4. 一个能让人物性格暴露的选择；
5. 至少一个对手/旁观者/门槛角色；
6. 一个没解决干净的余波。

读者第一次不需要知道完整学历、家庭、研究方向和十年弧光。

## 二、“三言两语勾人”靠外部信息，不靠作者简历

人物背景优先从以下渠道漏出：

- 别人怎么称呼他；
- 对方手里的简历/表格/名单；
- 一个动作暴露长期训练；
- 一句被别人追问的话；
- 对某件普通事异于常人的处理；
- 组织环境如何对待他；
- 他在哪个细节上显得过分熟练或过分生疏。

例如：

“博士，没论文？”比作者写“周野是一名零论文博士”更像小说。

“你这个表怎么连失败记录都有？”比作者写“周野重视可靠性”更有戏。

## 三、名字控制

开篇前六章执行强制限流：

- 单章新出现且需要读者记住的实名人物 <= 2；
- 非重复角色优先用职位/关系称呼：面试官、师姐、行政老师、店老板；
- 只有会再次进入故事的人，才值得尽早给姓名；
- 同一场景同时活跃的可记忆人物原则上 <= 4；
- 不在人物刚出场时连续介绍他的同学、导师、朋友名单。

## 四、人物“记忆钩”

每个核心人物第一次出场只给读者 4 个钩子：

1. **场面钩**：他第一次出现时在干什么；
2. **行为钩**：他遇事的第一反应；
3. **矛盾钩**：优点怎样已经露出一点阴影；
4. **声音钩**：他说话怎么和别人不同。

禁止用口头禅替代声音差异。

## 五、像电影分镜一样写，但不写成剧本

重要首次出场场景要求：

- 开场 1–3 段内必须出现可见动作；
- 500 字内出现压力或异常；
- 尽早出现对话；
- 背景说明每次不超过当前行动真正需要的量；
- 场景中必须有可见空间关系：门、桌、走廊、车站、窗口、会议室、租房、楼道等；
- 尽量让人物通过移动、拿取、等待、被打断、看错、停顿建立镜头感；
- 不用景物替人物总结人生。

## 六、用“他人视角”帮助人物立起来

《水浒传》式人物出场常借旁人反应迅速建立分量。本项目允许：

- 面试官的一句迟疑；
- 同事下意识把难事递给某人；
- 导师不给某种宽待；
- 一个陌生人误判角色身份；
- 一个弱关系人物先看到他的某一面。

但旁人不能充当全知评价者。

## 七、Campbell 弧光继续存在，但退到后台

首次出场主要负责 **Call / Ordinary World / Threshold 的可见压力**。

不解释“这是召唤”。不把十年弧光在第一场说透。

首次出场只应该回答：

> 这个人遇到世界时，世界先撞到了他的哪一块？

## 八、主角进入顺序改为“出场戏序列”

现有 Ch1–Ch6 暂时降级为素材与历史锚点，不继续默认它们就是出版版开篇。

新的开篇序列先做 3 个入口测试，每个只聚焦一个核心人物：

### Entrance A：周野——技术筛查

从 2027 年技术筛查开场。面试官问：别人怎么复跑、异常怎么记。简历里“博士、无论文”只作为压力背景闪现。复现包第一次在真实外部场景里有用。

优点：立即有压力、有对话、有结果；周野的“可靠”通过动作出现。

风险：时间从 2027 开始，需要后续通过极短回插交代这个包怎么来的，不能做长闪回。

### Entrance B：罗诚——行政楼门口

从一个学生材料临时变化、打印机卡纸、孙洁忙碌的现场开始；罗诚拿着招聘启事坐在那里等。读者先看到这份工作的真实劳动，再意识到他居然想来做这个。

优点：空间和人际摩擦强。

风险：仍偏制度场景，戏剧张力需靠罗诚本人被逼问经历不足。

### Entrance C：宋楠——行业面试第二轮

业务条件连续变化，对方追问“现在还敢不敢给结论”；她必须当场承认哪部分不能回答。学历和生存分析训练在交锋中暴露。

优点：外部世界强、节奏快、读者易懂。

风险：容易写成职场爽文，要保留卡壳、误判和边界。

先写 A 做第一轮测试。

## 九、出场场景验收

读完一个人物首次出场，测试读者能否在不看人物表的情况下回答：

- 他刚才遇到了什么事？
- 他最先做了什么？
- 他看起来擅长什么？
- 这个擅长之处哪里可能以后害到他？
- 他和其他人说话有什么区别？

如果答案只能是“他是某专业博士、想找某工作”，判失败。

## 十、禁止项

- 开头连续报姓名；
- 人物第一次出现就给完整履历；
- 旁白直接总结人物性格；
- 用一堆聊天记录代替场景；
- 为了制造抓人感强行车祸、疾病、背叛、犯罪等无历史支撑事件；
- 每个人首次出场都设计成“高光时刻”；
- 把《水浒传》学成章回体仿写。
