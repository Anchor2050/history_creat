# Campbell 人物弧光与留白规则 v2

本文件属于 adaptation-only 设计层。历史 ledger 不修改。

## 1. 基本原则

《千面英雄》负责人物长期变化的骨架，正文负责隐藏骨架。

Storyteller 可以知道人物处在 call、refusal、threshold、trial、descent、shadow、false return、transformation、return 或 post-return consequence；人物本人、旁白和其他角色不需要知道这些名称，也不需要完整理解自己正在发生什么。

长期弧线应足够清楚，单个场景应允许模糊、不完整、误判、偶然、拖延和无结论。

## 2. 后台完整，前台残缺

每个核心人物后台至少要回答：

- 他最初想要什么；
- 他为什么觉得这个目标合理；
- 他真正害怕失去什么；
- 哪个优点在压力下成为 shadow；
- 哪些门槛跨过以后旧生活无法原样恢复；
- 哪些试炼反复攻击同一处性格结构；
- 哪一次获得其实是假返回；
- 哪一种能力、判断或限制最终被带回日常生活；
- 这个 boon 又制造了什么新代价。

正文不应一次性回答这些问题。

## 3. 弧光不能太容易

人物变化必须受到四类阻力：

1. **认知阻力**：人物会误判自己，也会正确分析别人却分析错自己。
2. **情绪阻力**：知道正确做法，不等于当时做得到。
3. **利益阻力**：旧习惯往往真的给人物带来过收益、身份、尊严或安全感。
4. **环境阻力**：组织、权力、钱、时间、城市、关系会奖励某些旧性格，惩罚某些新尝试。

如果人物一被提醒就能理解、一理解就能改变、一改变就获得正反馈，弧光无效。

## 4. 转化必须允许反复

真正的 transformation 不应表现为永久升级。

允许：
- 已经学会授权的人下一次又插手；
- 已经接受失败的人下一次仍舍不得放手；
- 已经会设边界的人回到家庭关系里再次说砸；
- 已经做出主动选择的人过两年又怀疑自己；
- 已经迁移的人仍怀念旧生活中的一部分；
- 已经留下的人仍偶尔查看外部机会。

人物弧光应改变概率、阈值和恢复方式，不把人格缺陷删除。

## 5. 留白的五种来源

### 5.1 人物不知道
人物自己无法准确命名某个欲望或羞耻。旁白不要代替他说清。

### 5.2 人物不说
人物知道一点，但因为关系、尊严、疲惫或场合不适合而不说。

### 5.3 人物说错
人物用一个体面的理由解释自己，真实动机只在行为重复中逐渐显形。

### 5.4 场景不结算
一次冲突可以以开会、吃饭、下班、材料提交、电话挂断结束，没有情绪总结。

### 5.5 读者晚一点才知道
同一个动作几年后重复时，前一场的意义才变清楚。

## 6. 《千面英雄》的阶段不等于章节

禁止一章对应一个 stage。

一个 threshold 可以跨三章完成；一个 trial 可以持续四年；一个 shadow 可以先以优点出现，几年后才显出代价；一个 return 可以没有庆祝场景，只表现为人物以后处理事情的方式变了。

Storyteller 标 stage 是为了检查长期弧线，不是为了制造公式化节拍。

## 7. 不完整弧线也是合法弧线

2035 是观察终点。人物可以：
- 尚未完成 return；
- 完成一次职业旅程，又开始另一条关系或家庭旅程；
- 得到有限 boon；
- 只学会更快发现问题，还没学会解决；
- 明白自己有惯性，但仍选择留下；
- 学会结束项目，却暂时没有新项目。

未完成不等于失败，也不能为了闭环补剧情。

## 8. 六个核心人物的留白重点

### 周野
后台弧光：证明可靠 -> 被需要 -> 单点锁定 -> 授权 -> 有限去中心化。
正文留白：不要直接宣布他享受被需要。让这种矛盾从检查别人工作、插手冲动、对“谁算处理人”的反应、真正能休假以后产生。

### 高原
后台弧光：怕选错 -> 留下 -> 外部校准 -> 识别偏好与惯性混合。
正文留白：不要判决他究竟是勇敢留下还是害怕离开。到2035仍保留两种解释。

### 罗诚
后台弧光：身份名词 -> 岗位劳动 -> 拒绝与失败 -> 内容+平台双门槛 -> 第二次迁移。
正文留白：不要让他很早就承认自己在意“体面身份”。这件事应从他怎么描述岗位、如何介绍自己、被拒以后先伤到哪里慢慢出现。

### 唐雨
后台弧光：证明独立 -> 坚持 -> 收缩 -> 成果 -> 空档 -> 快速杀掉新题。
正文留白：不要写成她终于学会放弃。她依然可能很倔，只是负面证据进入决定的时间更早。

### 何欣
后台弧光：稳定目标 -> 稳定积累 -> 路径依赖 -> 岗位价值复核 -> 购房。
正文留白：不要替她判断买房是成熟承诺还是路径依赖加深。两种意义长期共存。

### 宋楠
后台弧光：最大化学习 -> 高成本增长 -> 主动换城 -> 接受多目标 bundle。
正文留白：不要把第二份工作写成正确答案。她得到生活收益，也真实放弃了一部分机会密度和收入。

## 9. 每章弧光检查

写完一章后只在后台回答：

- 这章触碰了哪个长期 stage？
- 人物的哪个稳定内核被测试？
- shadow 有无出现？若出现，正文有没有直接解释？
- 这章改变的是行为、阈值、关系、资源、理解，还是其实什么也没改变？
- 有没有为了完成弧光而让人物过早自知？
- 有没有给人物一个太完整的情绪闭环？
- 有没有允许错误、偶然和环境力量保留自己的作用？
- 删除最后一段后，人物弧是否仍可被长期结构支撑？

## 10. 反完美规则

出现以下情况时，默认视为需要重写：

- 人物一次谈话后准确理解自己；
- mentor 给出正确答案，人物照做后立刻受益；
- 缺点被一次事件永久修复；
- 每次试炼都有明确收获；
- 每章都有一个漂亮的心理结论；
- 每个角色都能清楚说出自己的边界、需求和成长；
- 偶然事件只服务人物成长；
- 环境总是公平地奖励成熟决定；
- 所有重要伏笔最终都被解释。

## 11. Storyteller 的执行口径

长期人物弧光优先级高于单章主题完整度。

正文允许少解释、少解决、少总结，但长期必须看见：同一个人经过世界以后，在若干关键阈值、反复试炼和 shadow 暴露中，做事的方式、承受代价的能力、看世界的角度发生了可追踪变化。

弧光是暗线。留白是显现方式。
