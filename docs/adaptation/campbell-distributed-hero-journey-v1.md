# Campbell / 《千面英雄》在本项目中的改造用法 v1

本文件属于 adaptation-only 设计层，不修改 2026–2035 历史 ledger。

## 一、先校正来源

Joseph Campbell 的《The Hero with a Thousand Faces》（《千面英雄》）原本是比较神话学著作，不是小说教材。它讨论不同文化神话中反复出现的“单一神话 / monomyth”结构。后来 George Lucas 明确承认其对《Star Wars》的结构影响；Christopher Vogler 又把相关思想整理为更直接的编剧工具。

本项目借鉴 Campbell 的思想，但不照抄固定阶段表。

## 二、本项目真正要借的四个核心思想

### 1. 阈值：人生真正改变，往往始于跨过某个不可完全撤回的门槛

阈值可以是：
- 博士毕业；
- 第一次正式工作；
- 第一次真实迁城；
- 买房；
- 主动放弃某条研究命题；
- 选择继续留任；
- 公开承认一种职业身份。

重点不在“发生大事”，而在跨过去以后旧生活结构已经不能原样恢复。

### 2. 试炼：真正塑造人物的是重复摩擦，不是一次高潮

英雄之旅里的 trial，在现实主义作品里应被拆成：
- 一次次公开流程；
- 小失败；
- 等待；
- 关系降频；
- 工作中反复出现的责任；
- 钱、时间、住房、城市的累积约束；
- 一个问题反复被反例攻击。

试炼不是“打怪清单”，而是人物内核在不同压力下反复暴露。

### 3. 怪物往往和人物自身同源

每个核心人物的真正对手不只是外部制度，也包括自己优点的阴影：

- 周野：可靠性 -> 无限兜底；
- 高原：谨慎 -> 路径依赖合理化；
- 罗诚：适应性 -> 对身份标签的依赖；
- 唐雨：研究强度 -> 不肯及时放手；
- 何欣：边界感 -> 回避更直接的冲突；
- 宋楠：行动力 -> 节奏压迫别人。

英雄成长不是消灭这些特质，而是学会识别何时它们开始反过来控制自己。

### 4. Return：返回时带回来的不一定是“胜利”，而是一种新的能力

传统神话里英雄会带回“boon”。在本项目里，返回物可以是：
- 一套能让别人接手的工作标准；
- 更清楚的职业门槛；
- 更快停止错误项目的能力；
- 对住房锁定的清醒；
- 承认某种生活结构确实适合自己；
- 承认某种方法还不能独立移交；
- 学会让一个问题自然结束。

返回物首先改变本人，之后才可能改变组织或关系。

## 三、从“单一英雄”改成“分布式英雄旅程”

本项目不设置唯一 Luke Skywalker。

六个核心人物各自拥有不同步、部分重叠、并且可能中断的英雄旅程。一个人处于“召唤”时，另一个人可能已经在“返回”；一个人完成的是职业旅程，另一个人完成的是研究判断旅程。

这能保留群像最重要的东西：

- 没有人拥有唯一正确的人生顺序；
- 不同角色互相充当 mentor、threshold guardian、shadow、ally、mirror；
- 同一个人可以在不同人的故事里扮演不同原型；
- 原型是关系功能，不是固定人物标签。

## 四、原型只作为“关系功能”使用

禁止把人物脸谱化成：导师=Mentor、领导=Threshold Guardian、竞争者=Shadow。

同一个人物在不同场景中可以是：
- mentor：提供一个别人尚未看到的判断；
- threshold guardian：代表制度边界；
- shadow：暴露主角不愿承认的另一种可能；
- ally：帮助但不替代主角承担后果；
- trickster：用玩笑、失败或意外打破主角原有解释；
- herald：带来一个新信息、新机会或新危机。

这些角色必须由具体场景和关系决定。

## 五、六个核心人物的 Campbell 弧线草图

### 周野：从“证明可靠”到“允许系统不依赖自己”
- Ordinary world：零论文、博士末期，自我价值难被外部识别。
- Call：必须把“可靠”做成可检查证据。
- Trials：复现、交接、复杂异常越来越集中。
- Abyss / shadow：被依赖既给他尊严，也让他成为单点。
- Transformation：培养第二判断者。
- Return：可靠最终变成系统能力，而非个人牺牲。

### 高原：从“怕选错”到“允许阶段性选择成立”
- Call：公务员/稳定生活。
- Refusal/hesitation：长期比较、害怕不可逆迁移。
- Trials：考试、市场刷新、同龄人变化、门槛审计。
- Shadow：谨慎可能只是恐惧的高质量解释。
- Transformation：学会把真实偏好与沉没成本分开。
- Return：继续留下，但留下成为被外部校准的主动选择。

### 罗诚：从“找一个能解释学历的身份”到“用工作内容定义自己”
- Call：高校辅导员/体面制度身份。
- First failure：学生事务线不成立。
- Descent：职业标签失效，博士身份不能直接兑换岗位。
- Trials：研究支持、第一次中期申请失败、可迁移案例。
- Transformation：内容+平台双门槛。
- Return：多年后第二次迁移，岗位名不再是主要自我解释。

### 唐雨：从“坚持证明自己”到“有能力及时停止”
- Call：独立研究问题。
- Trials：大命题、反例、收缩、再失败、外审。
- Reward：边界论文被接受。
- False return：接受并没有自然产生下一项目。
- Second descent：研究空档。
- Transformation：新小项目很快被反例关闭。
- Return：她真正带回来的能力，是让负面证据有权结束一个项目。

### 何欣：从“稳定是目标”到“稳定是需要持续复核的结构”
- Call：事业单位/稳定生活。
- Trials：两次买房失败、学习增长变慢、福利与路径依赖增强。
- Shadow：边界与稳定也可能变成回避变化。
- Transformation：先检查岗位价值，再决定住房。
- Return：第三次才购房，而且继续把职业与资产分别复核。

### 宋楠：从“最大化学习”到“接受多目标的人生 bundle”
- Call：医药统计、高学习密度。
- Trials：高房租、远家庭、机会与生活冲突。
- Threshold crossing：主动降薪换城。
- Trials after crossing：学习变慢、协调变重。
- Transformation：不再要求一个选择在所有维度都更好。
- Return：保留专业判断，同时接受更可持续的生活结构。

## 六、英雄旅程必须和“矛盾人格模型”结合

任何转化都必须回答：

1. 人物的哪一个稳定内核被挑战？
2. 哪个优点开始产生阴影？
3. 外部权力结构如何放大或抑制这个阴影？
4. 这次试炼触发什么情绪？
5. 人物有没有拒绝召唤、拖延、误判？
6. 这次得到的“boon”是什么？
7. boon 是否同时带来新代价？

如果没有这些具体内容，就不算英雄旅程，只是机械结构套用。

## 七、禁止事项

- 不把六个人全部套成同样 12/17 阶段。
- 不给每个人安排一个大反派。
- 不把 mentor 固定成导师。
- 不把失败写成命定的成长铺垫。
- 不强制“归来即成功”。
- 不把人物转化写成一句“他终于明白了”。
- 不为了完成 arc 制造家庭灾难、死亡、疾病或爱情。

## 八、对 Storyteller 的实际用途

Storyteller 下一阶段在挑 20–30 个关键场景时，每个场景额外标记：

- hero_stage_function：ordinary / call / refusal / threshold / trial / descent / insight / return / post-return consequence；
- active_archetype_roles：谁在此场景中承担 mentor / ally / shadow / guardian / herald / trickster 功能；
- inner_conflict：人物哪个优点与阴影发生冲突；
- transformation_delta：场景是否真的改变人物，若没有则为空；
- boon_or_cost：此场景带回什么能力/资源/代价；
- evidence_refs：必须回链历史 ledger。

这些标签只用于结构分析，不直接出现在小说正文。

## 九、核心原则

《千面英雄》给我们的不是一套公式，而是一种观察人物变化的语言。

我们真正想保留的是：

一个人走出去，经历世界；世界改变他；他带着新的能力、伤痕、判断和局限回来；然后新的生活又重新开始。

六个人都在走，但没有人走同一条路。
