# 核心人物心理与人格 Bible v1

本文件属于 **adaptation-only character design**。它不回写 2026–2035 历史 ledger，也不宣称这里的所有人格细节已经作为历史事实发生。

目的：防止正文把所有人物写成同一种理性、克制、会复盘、会说漂亮话的人。

历史层提供的是行为、选择、关系与后果。改编层在不违反这些证据的前提下，为人物建立可持续的性格、情绪与视角差异。

---

## 一、人物必须同时有三层

### 1. 稳定内核

长期较难变化，包括：
- 尊严主要来自哪里；
- 最怕被别人怎样看；
- 风险偏好；
- 对钱、时间、工作、关系的基本秩序感；
- 道德底线和不愿交换的东西；
- 基本文化/专业素养；
- 处理不确定性的习惯；
- 说话与理解信息的方式。

稳定内核不能为了某一章戏剧需要随意改变。

### 2. 情绪状态

短期、情境性的：
- 兴奋；
- 羞耻；
- 嫉妒；
- 恼火；
- 振奋；
- 疲倦；
- 怯懦；
- 侥幸；
- 内疚；
- 麻木；
- 松一口气。

情绪必须有触发来源，也必须符合人物自己的表达方式。不同人物面对同一事件，强度、持续时间、是否外露都不同。

### 3. 人性弧线

长期变化只从反复行为和后果中生长。

人性弧线不等于“人物变成熟”。有人可能更敢承担，有人更会退出，有人只是更清楚自己的局限，有人变得更谨慎，也有人留下新的自我欺骗。

---

## 二、几个硬规则

1. **勇敢不是单轴属性。**
   - 可以职业上大胆、亲密关系里回避；
   - 可以敢承担失败，却怕承认羡慕；
   - 可以敢换城市，却不敢和家人冲突。

2. **聪明不等于自知。**
   - 数学博士也可能很会推理，却不理解自己为什么生气；
   - 很会复盘工作，也可能在人际上重复犯错。

3. **情绪不自动转成独白。**
   - 很多人不知道自己在难过；
   - 有人会把羞耻说成“麻烦”；
   - 有人会把焦虑变成查资料；
   - 有人会突然话多；
   - 有人会变得极其客气。

4. **人物不能都擅长总结人生。**
   正文中的意义主要来自行为、对话差异和多年重复，不靠人物轮流发表主题演讲。

5. **性格必须制造代价。**
   任何优点如果从不制造麻烦，就只是人设标签。

# 三、六名核心人物

## 周野

### 稳定内核
- **尊严来源**：把事情做对、做稳，别人拿过去能用。
- **最怕被怎样看**：没产出、没用，只会说自己认真。
- **基本气质**：内敛、慢热、耐烦，对技术问题比对人的态度更有把握。
- **风险方式**：不喜欢无信息下注，但一旦判断条件够了，可以承担很长期的后果。
- **秩序感**：强。习惯把焦虑改写成清单、版本、检查项。
- **道德底线**：不喜欢抢功，也很反感把别人依赖自己包装成“我不可替代”。
- **盲点**：容易把“我来兜底”误当成责任感；不善于在问题还没爆炸时开口说自己累了。

### 情绪动力学
- 羞耻来得比愤怒快，尤其涉及“零论文”“你到底会什么”。
- 恼火通常不当场发作，会先变得更简短、更程序化。
- 真正高兴时也不外放，常表现为愿意多讲一点技术细节。
- 被依赖早期会有一点隐秘满足，后来才发现那也是负担。

### 勇敢与怯懦
- **勇敢**：承担长期技术责任；在条件成熟后接受买房这种真实锁定；后来愿意培养第二判断者。
- **怯懦**：早期不太敢直接说“我其实怕自己没有竞争力”，更愿意说“我再准备充分一点”。

### 视角滤镜
进入一个新环境，他先看：流程乱不乱、谁负责、出问题以后有没有记录、东西交给别人能不能复现。

一场饭局上别人说“这个岗位挺稳定”，他脑子里先出现的是：具体职责是什么、技术是不是还能积累、几年后还能不能换。

### 说话方式
- 句子偏短。
- 不爱先讲感受，爱先讲事实。
- 真正不同意时会问具体问题，不太直接说“大方向不对”。
- 不擅长漂亮安慰，但会帮你把东西看完。

### 十年弧线
从“我要证明自己可靠”走到“可靠不能等于所有事都由我处理”。

内核没有变：他仍然重视把事情做稳。
变化的是，他终于接受**一个系统如果离不开自己，并不一定证明自己做得好**。

## 高原

### 稳定内核
- **尊严来源**：生活有秩序，决定能说得通，不给家里添太多不可控。
- **最怕被怎样看**：没胆子、没追求、只是给自己的停留找借口。
- **基本气质**：谨慎、克制、耐长期重复，比别人更能忍受“暂时没有答案”。
- **风险方式**：高度看重下行风险，做决定前会把坏结果想得很具体。
- **秩序感**：对时间、考试、生活安排都较强。
- **道德底线**：不喜欢用家庭责任当挡箭牌，也不愿为了显得有野心去做自己不信的选择。
- **盲点**：很会给决定找完整理由，因此也最容易把路径依赖解释得过分合理。

### 情绪动力学
- 焦虑常表现为重复比较、重新搜岗位、再算一次。
- 振奋不是“我要改变人生”，更多是突然发现一个选项居然真的可行。
- 羡慕别人时会先否认，随后通过比较参数来处理。
- 低落持续时间较长，但外表变化不大。

### 勇敢与怯懦
- **勇敢**：能长期承受别人觉得他“没动”；也愿意反复打开市场检验自己的留任理由。
- **怯懦**：对不可逆的变化天然更怕，尤其是没有明确回头路的迁移。

### 视角滤镜
他看选择时最先注意：最坏会怎样、父母距离、住房成本、工作时间有没有被吃掉、后悔以后能不能回来。

别人看到“机会”，他先看到“退出条件”。

### 说话方式
- 说话完整，喜欢把前因后果交代清楚。
- 容易出现“我不是不想……我主要是……”这种自我辩护倾向；正文要控制，不能每次都让他说透。
- 真被戳中时反而会沉默或换话题。

### 十年弧线
从“怕选错”走到“允许一个选择只是当前阶段合理”。

他没有变成冒险者。
他学会的是：**谨慎也需要接受外部校准，否则谨慎会慢慢变成自我封闭。**

## 罗诚

### 稳定内核
- **尊严来源**：自己能在一个组织里真正解决问题，而不是只靠学历名称占位置。
- **最怕被怎样看**：读了这么多年书，最后什么专业身份都没有。
- **基本气质**：比周野、高原更愿意和人打交道，也更容易从别人反馈里调整自己。
- **风险方式**：愿意尝试，但很在意“这次改变是不是又只是换了个标签”。
- **秩序感**：中等。他比前两人更能容忍模糊和现场变化。
- **道德底线**：不愿把自己没做过的人际/学生工作经历编成职业故事。
- **盲点**：早期容易被“岗位名称”“高校身份”吸引，低估真实工作内容的重要性。

### 情绪动力学
- 被拒以后会明显沮丧，也会有一点自嘲。
- 情绪恢复主要靠做下一件具体事、找人聊，而不是自己闷很久。
- 得到认可时比较外露，会更愿意说话，也容易一时把未来想得太好。

### 勇敢与怯懦
- **勇敢**：职业身份被打碎后能重建；第一次中期申请失败以后仍守住内容门槛。
- **怯懦**：早期怕承认“我其实不知道自己适合什么”，因此会抓住看起来体面的岗位标签。

### 视角滤镜
他进一个单位先看人怎么配合、事情卡在哪个接口、谁知道信息、谁只是转发信息。

相比职位名，他后来越来越会观察“这个岗位每天到底在解决什么问题”。

### 说话方式
- 相对有人情味，愿意讲具体经历。
- 有时会用自嘲降低尴尬。
- 对熟人比对陌生人话多。
- 失败时不太会发表深刻感言，更可能说“行，那我再看看”。

### 十年弧线
从“我要找一个能解释博士学历的岗位”，走到“我要找一个内容本身值得我迁移的岗位”。

他的成长核心是**身份从名词变成动词**：不再执着自己叫什么，而更在意自己每天究竟在做什么。

## 唐雨

### 稳定内核
- **尊严来源**：问题必须真的成立，论证经得住挑。
- **最怕被怎样看**：只会跟热点、靠导师、靠包装成果，没有自己的问题判断。
- **基本气质**：较强烈、较要强，智力竞争感明显；对研究比对生活更容易产生情绪波动。
- **风险方式**：研究上敢押长期题，生活决策反而可能更谨慎。
- **秩序感**：对论证要求高，对生活未必处处规整。
- **道德底线**：不愿把失败命题包装成成功故事，也不能接受明知边界有问题仍夸大结论。
- **盲点**：容易把长期投入和问题价值绑在一起；早期会因为“已经做这么久”而更难放手。

### 情绪动力学
- 研究被质疑时第一反应可能是防御和恼火，不会立刻平静地说“谢谢这个反例”。
- 证明推进时会非常兴奋，甚至暂时忽略生活其他部分。
- 真正被反例击中后有短期低落、羞耻和不服，随后才进入检查。
- 空档期最难受的不是“没成果”，而是脑子里没有一个她真正想追的问题。

### 勇敢与怯懦
- **勇敢**：敢押难题；后来也敢承认大命题错、缩小、停掉，甚至三个月关掉新项目。
- **怯懦**：早期很怕“停下来以后证明自己其实没有下一题”，因此容易用继续工作逃避空白。

### 视角滤镜
她看别人的研究，第一眼会找：关键假设在哪、反例有没有、这句话到底证明了什么。

她在饭局里可能对别人职业细节听得不如宋楠认真，但如果一句话碰到“这个方法是不是其实不成立”，她会立刻进入状态。

### 说话方式
- 比其他人更直接。
- 对专业问题会追问，很少用模糊安慰。
- 情绪上来时语速快、问题密。
- 真正泄气的时候反而可能说得很少。

### 十年弧线
从“坚持证明自己有能力做成一个大问题”，走到“判断力也包括尽早杀掉一个不值得做的问题”。

她的核心没有变：仍然认真、较真、想做真的问题。
变化的是，她不再把**持续时间**当作问题价值的证据。

## 何欣

### 稳定内核
- **尊严来源**：生活和工作在自己可承受的范围内，不被别人用‘应该’推着走。
- **最怕被怎样看**：因为求稳定就被认为没能力、没野心；或者因为家里情况被默认应该承担某种角色。
- **基本气质**：克制、边界感强，观察多于表达，不喜欢被迫表态。
- **风险方式**：偏谨慎，但不是高原式反复搜索；她更依赖明确底线和不做什么。
- **秩序感**：强，尤其在钱、时间、家庭协商上。
- **道德底线**：不接受把家庭借款、兄弟责任或女性身份当成理所当然的可调用资源。
- **盲点**：很会判断“能不能忍”，因此可能把“尚可”维持太久，较晚才问“我到底还从这里得到什么”。

### 情绪动力学
- 压力大时更安静、更客气，不太会爆发。
- 真正生气往往来自别人替她做决定，或把她的边界当成矫情。
- 安心感对她非常重要，但安心久了也可能变成麻木。
- 她的振奋通常很轻：一件事情终于可以由自己决定，或者一笔账终于清楚。

### 勇敢与怯懦
- **勇敢**：两次不买房也不把它视为失败；先审工作再决定住房；最终买房后仍保留重新评价工作的权利。
- **怯懦**：对破坏已有稳定结构的选择天然拖延，容易先等到“不得不动”的证据。

### 视角滤镜
她遇到选择先看：钱够不够、后果谁承担、有没有隐性义务、现在答应以后还能不能改。

别人讲“发展机会”，她会先问这机会具体占多少晚上和周末。

### 说话方式
- 话不多，但问题往往很实际。
- 不轻易跟着别人激动。
- 会用很平常的句子把边界说清楚。
- 真不愿意时，很少解释一大堆，可能就一句“这个我先不算进去”。

### 十年弧线
从“我想要稳定”，走到“稳定必须拆开来看：钱、工作内容、城市、福利、住房、退出成本分别是什么”。

她没有变成追求高风险的人。
她变得更敢问：**一个我能忍受的生活，是不是就等于我愿意继续的生活。**

## 宋楠

### 稳定内核
- **尊严来源**：自己能解决真实问题，专业能力在不同组织里都读得懂。
- **最怕被怎样看**：只会某一家公司的流程，一离开平台就没有价值。
- **基本气质**：六人里相对外向、行动快、愿意接触新环境；对行业和人都有好奇心。
- **风险方式**：能承受可计算的变化，比高原、何欣更愿意试；但不喜欢无边界的冒险。
- **秩序感**：工作里强，生活里更有弹性。
- **道德底线**：不拿客户/公司敏感材料给自己包装成绩；不把关系当资源提款机。
- **盲点**：容易把“新东西多”当成成长，把高强度误认成高价值；早期也容易高估自己能长期扛住房和距离成本。

### 情绪动力学
- 兴奋来得快，也比较外露。
- 受挫后恢复通常比唐雨快，会先找替代路径。
- 累的时候会抱怨，会开玩笑，不太把一切憋成深刻沉默。
- 真正不安时反而会开始整理材料、做案例、问外部市场。

### 勇敢与怯懦
- **勇敢**：主动进入行业；后来也敢接受降薪、低机会密度换更可持续的城市生活。
- **怯懦**：很怕自己的专业价值离开平台后不成立，因此在真正跳槽前必须先证明技能可迁移。

### 视角滤镜
她进一个新岗位先看：这个问题谁真的需要答案、结果最后拿去做什么决定、跨团队沟通顺不顺、自己有没有判断权。

她比其他几个人更容易注意城市生活、同事气氛、通勤和人的状态。

### 说话方式
- 相对快、自然、会开玩笑。
- 愿意讲行业里的具体荒唐事。
- 不太喜欢长篇抽象自我分析。
- 做重大选择时反而会突然变得很具体：工资多少、租金多少、多久回家一次、工作里到底能决定什么。

### 十年弧线
从“我要在最能学东西的地方多学”，走到“成长不只看新东西有多少，也看这种生活能不能长期支持我的判断能力”。

她的行动力没变。
变化的是，她学会把**生活可持续性也算进职业能力的成本函数**，但正文中不要让她真的说出“成本函数”这种主题化台词。

# 四、写场景时必须先回答的九个问题

每个核心人物进入重要场景前，adaptation runtime 必须先回答：

1. 他此刻最想要什么？
2. 他最不想让别人看见什么？
3. 这件事碰到了他的哪条稳定内核？
4. 当前主情绪是什么？次情绪是什么？
5. 情绪是外露、压住、转成行动，还是转成别的话题？
6. 他在这个领域更勇敢还是更怯懦？
7. 他第一眼会注意这个场景里的什么？会漏掉什么？
8. 他会怎么说，而不是“一个聪明人会怎么说”？
9. 这场结束后，他有没有真的改变？如果没有，保持原样也是有效结果。

# 五、不同人物面对同一事实的差异示例

事实：一个外地岗位工资更高，但工作内容不确定，需要搬家。

- **周野**：先问职责和技术所有权，再算迁移后技术积累是否中断。
- **高原**：先看最坏情况、回不回来、父母距离、住房和时间结构。
- **罗诚**：先找实际在岗的人问一天都做什么，警惕职位名好听但内容重复。
- **唐雨**：如果岗位能保留研究，会先追问研究自主到底是真还是宣传；如果和研究无关，她兴趣下降得很快。
- **何欣**：先算现金、隐性时间、退出成本和家庭义务有没有被偷偷默认。
- **宋楠**：先问真实业务问题、判断权、学习曲线，再把工资、房租、通勤和回家频率一起算。

同一条信息在六个人脑子里不能生成同一套分析。

# 六、后续工作

下一步不直接写长篇。

先从历史 ledger 选 20–30 个 scene reservoir；每个 scene 在试写前加载：
- ledger facts；
- 当年 Personal snapshot；
- 本 Character Bible；
- 双方关系历史；
- 当前情绪候选；
- 文风 guardrails。

每个 scene probe 写完后再检查：
