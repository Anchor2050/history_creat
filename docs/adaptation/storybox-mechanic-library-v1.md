# StoryBox 机制库 v1

> adaptation-only。目标：把剧本杀、社交推理、调查、资源管理、地图探索、竞合与 campaign/legacy 类桌游中可复用的叙事机制抽象成机制原语。StoryBox 组合机制，不复制任何具体商业游戏的角色、剧本、文本或谜题。

## 1. 为什么需要机制库

规则合法不等于游戏精彩。高手局需要：

- 信息不对称，但不能完全随机；
- 每轮行动留下可推理痕迹；
- 决策有机会成本；
- 角色有局部目标，也有跨局长期状态；
- 主持人能控制节奏，却不能篡改已经固定的 truth；
- 存在公开证据、私有信息、错误信念和策略性表达；
- 局面允许多种合理策略，不能只有一条“正确路线”；
- 游戏能收敛、僵持、失败或把矛盾转移到下一局。

StoryBox 需要从机制库中选择若干机制组合成一个 Game/Event Arc，而不是所有事件都用同一套“对话 + 查线索”。

## 2. 机制原语

### A. Hidden-role / hidden-interest

角色拥有未公开的忠诚、利益、承诺、风险暴露或制度身份。

关键不是“谁是坏人”，而是：

- 谁知道自己的局部利益；
- 谁知道别人的一部分利益；
- 谁必须伪装、隐瞒或模糊表达；
- 公开行为会留下什么可推理痕迹。

现代现实题材优先使用 `hidden_interest`、`hidden_commitment`、`hidden_exposure`，慎用纯二元善恶身份。

### B. Asymmetric information

不同角色对同一事实拥有不同分辨率的信息。

可拆为：

- truth：后台固定事实；
- observation：角色实际看到；
- belief：角色如何解释；
- claim：角色公开说了什么；
- reader_view：Storyteller 让读者知道多少。

### C. Public evidence trail

每轮留下公开可复查痕迹：

- 投票；
- 队伍/小组选择；
- 报告签名；
- 日志；
- 时间戳；
- 谁主张了什么；
- 谁在什么时候改变立场；
- 哪个任务成功/失败。

高手局必须让聪明角色有东西可以推理，不能全部依赖作者后来塞新证据。

### D. Secret action / private channel

允许私聊、密报、私下交易、保留信息、延迟披露、局部联盟。

必须记录：

- 谁知道这次私下行动存在；
- 行动是否留下痕迹；
- 信息能否合法跨 Game；
- 如果泄露，泄露本身是否构成事件。

### E. Proposal + vote + mission

适合：委员会、联合项目、政策选择、组队执行、审查、评审。

结构：

1. 某人提出方案/团队；
2. 其他人公开或私下表态；
3. 执行者进入任务；
4. 得到部分公开结果；
5. 结果不能完全识别每个参与者贡献。

这会自然制造“结果是证据，但不是身份证明”。

### F. Moderator-controlled information

主持人依据固定 truth、角色能力、信息权限和当前状态决定：

- 谁在何时收到什么；
- 信息精度；
- 是否带噪声/歧义；
- 哪些结果只能用 yes/no、范围、排名或部分字段表达。

主持人不得为了戏剧性临时改 truth。

### G. Investigation / clue economy

调查不是无限免费搜索。

每个调查动作消耗至少一种：

- 时间；
- 权限；
- 人情；
- 金钱；
- 声誉；
- 暴露风险；
- 机会成本。

线索具有：来源、可靠度、可验证性、访问条件、潜在误导、回收窗口。

### H. Action points / attention budget

角色每轮/每 Scene 有有限行动预算。

现实映射：

- 时间；
- 注意力；
- 体力；
- 可调用下属；
- 正式权限；
- 认知负荷。

高影响力角色拥有更大资源和代理能力，但也有更多并发承诺。

### I. Resource conversion

不同资源之间可以转换但有损耗：

- 钱换速度；
- 权力换访问；
- 声誉换别人信任；
- 人情换信息；
- 时间换验证精度；
- 技术能力换更低的不确定性。

禁止无限资源和无成本调用。

### J. Map / jurisdiction unlock

地图不仅是地理。

节点可以是：

- 部门；
- 数据库；
- 医院；
- 实验室；
- 会议室；
- 家庭；
- 社交群；
- 媒体空间；
- 法律/行政程序；
- 某个人的私人关系网。

解锁必须带来新信息源、合法动作、新约束或新势力。

### K. Phase / clock / deadline

Game 可以有昼夜、阶段或倒计时：

- 调查期；
- 协商期；
- 决策期；
- 公布期；
- 余波期。

时间推进本身会改变合法动作、证据可用性、舆论、资源和人物疲劳。

### L. Simultaneous action

多个角色同时提交行动，主持人再解决冲突。

适合：

- 谁先公开声明；
- 谁先联系媒体；
- 谁抢先冻结系统；
- 谁先找关键人；
- 谁先保护证据。

可避免所有角色永远按作者顺序排队行动。

### M. Bluff / cheap talk / costly signal

角色可以撒谎、模糊、试探或表演。

区分：

- cheap talk：说错成本低；
- costly signal：说错/做错会留下责任、金钱、职位或声誉成本；
- binding commitment：承诺后会限制后续动作。

### N. Role ability / exception rule

角色能力可以打破一般规则，但必须来自真实能力/职位/关系：

- 法务能阻止某类公开；
- 技术负责人可直接看部署日志；
- 医院数据管理员能确认字段来源；
- 高层可临时调配资源；
- 熟人关系可打开私人沟通通道。

能力不是超能力；有范围、冷却、权限边界和代价。

### O. Persistent campaign / legacy

Game 结束后保留：

- 关系变化；
- 声誉；
- 新制度；
- 地图解锁；
- 未偿承诺；
- 伤痕/疲劳；
- 错误信念残余；
- 技能增长；
- 新敌友关系；
- 未回收伏笔。

下一局从这些后果开始，而不是人物重置。

### P. Multi-game portfolio

一个角色可同时参加多个 Game。

每个 Game 单独记录：

- role；
- stake；
- stance；
- authority；
- private information；
- obligation。

同一角色可在不同 Game 中表现为合作、阻碍、中立、投机、保护者或被动对象。禁止全局 hero/villain 标签。

### Q. Event node / convergence gate

一个“大事件节点”只有在若干 Game/Scene 满足条件后才触发。

例：

- 系统暂停；
- 负责人辞职；
- 文件公开；
- 联合调查成立；
- 项目继续但收缩范围；
- 某人被正式授权；
- 某人失去权限。

大事件是前置博弈挣出来的结果，不是作者想推进就发生。

## 3. 高手局质量指标

### 3.1 信息可推理性

聪明角色仅凭已公开/已获得的信息，应该能形成比普通角色更好的判断。

如果高手与新手唯一差异只是“作者让高手猜对”，失败。

### 3.2 多策略可行

同一局至少允许两种以上合理策略：

- 快速冻结 vs 有条件继续；
- 公开不确定性 vs 先内部核验；
- 直接问关键人 vs 先保护证据；
- 把资源集中给一个专家 vs 分散验证。

### 3.3 局部最优冲突

每个角色按自己局部信息和激励做出的合理动作，组合后可以造成系统性坏结果。

这是现实张力的主要来源之一。

### 3.4 强者有代价

高能力/高权力角色不能成为万能解题器。

他们通常面临：

- 并发负荷；
- 信息过载；
- 代理链失真；
- 过度依赖；
- 责任聚集；
- 立场暴露；
- 跨 Game 承诺冲突。

### 3.5 主持人中立但非机械

StoryBox 主持人：

- 维护 truth；
- 执行规则；
- 决定合法信息输出；
- 解决同时行动；
- 触发硬世界事件；
- 检查收敛。

主持人不能：

- 替角色选择“更好看的动作”；
- 为了高潮泄露关键真相；
- 为了保护喜欢的角色改变规则；
- 让一方无故变笨。

## 4. 机制组合原则

每个 Game 只选必要机制，通常 2–5 个主机制足够。

示例：

### 风险名单 · 原因重建局

- asymmetric information
- investigation/clue economy
- map/jurisdiction unlock
- moderator-controlled information
- deadline

### 风险名单 · 72h说明局

- proposal + vote/approval
- public evidence trail
- costly signal
- deadline
- multi-game spillover

### 风险名单 · 泄露路径局

- private channel
- investigation
- bluff/withhold
- reputation spillover
- map unlock

### 风险名单 · 试点决策局

- proposal
- coalition/vote
- resource conversion
- public commitment
- event-node gate

## 5. 反模式

拒绝：

- 每局都隐藏身份；
- 每局都调查谜题；
- 每轮都必须有人撒谎；
- 每个角色都拥有特殊技能；
- 每个 Scene 都有反转；
- 主持人为了“平衡”强行给弱方新线索；
- 所有机制一次性全开；
- 规则复杂度超过人物与事件本身；
- 把现实人物硬分成好人/坏人两队。

## 6. 核心句

StoryBox 的目标不是模仿某一款桌游。

它要做的是：

**把现实社会中本来就存在的信息不对称、资源有限、权限边界、联盟、误解、竞争、合作、承诺与历史后果，表达成可以运行、可以收敛、可以推演的游戏机制。**
