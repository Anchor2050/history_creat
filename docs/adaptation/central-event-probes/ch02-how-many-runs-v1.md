# 中央事件开篇试写 · 第二章：昨晚一共有几批

> adaptation-only disposable prose。只承接第一章最后的发现：外泄截图早于当前批次，因此必须冻结并重建昨夜全部运行。新人物只有在当前问题需要其信息时进入。

昨晚一共有三批。

第一批，二十三点三十一。

第二批，二十三点四十六。

第三批，二十三点五十一。

罗诚把三个时间写在白板上。

主任问：“截图是哪批？”

“第二批。”

“我们早上打印的是第三批。”

“对。”

“第一批呢？”

“还没找到导出记录。”

主任看了一眼九点前要回复的邮件。

“先别说‘没用过’。”

罗诚把准备写进初步说明的那句话删掉。

八点三十四，技术方的视频会议接通。

屏幕那边先出现一个值班工程师。

“我们确认昨晚确实有三次任务。”

“为什么三次？”主任问。

“第一次是定时任务。第二次是手工重跑。第三次是系统自动重试。”

罗诚问：“谁手工重跑的？”

“请求从医院接口那边过来，我们这边执行。”

“为什么要重跑？”

“工单只写了‘最新数据已补，请重新生成名单’。”

主任说：“执行的时候用的哪个版本？”

工程师停了一下。

“日志里是 `v3.4.2`。”

“为什么不是 `v3.5.0`？”

“昨晚有一次部署回滚。”

主任往前坐了一点。

“这个早上没人说。”

“我也是刚看到。”

“谁能把回滚过程说清楚？”

值班工程师低头打字。

“我拉一下昨晚负责发布的人。”

两分钟后，会议里多了一个头像。

名字：周野。

他没开摄像头。

第一句话是：“我先说能确认的。”

罗诚抬头看屏幕。

周野共享日志。

二十三点二十九，`v3.5.0` 发布任务开始。

二十三点三十二，健康检查失败。

二十三点三十三，系统自动回滚到 `v3.4.2`。

二十三点三十一那一批，正好卡在发布和回滚之间。

主任问：“所以第一批到底跑的哪个？”

“正在查容器实例。”周野说，“任务标签写 `v3.5.0`，实际实例未必。”

“第二批呢？”

“确定是 `v3.4.2`。”

“第三批？”

“也是。”

值班工程师说：“那原因不就很清楚了吗？回滚导致旧版本跑了两次。”

周野没接。

主任问：“你不同意？”

“只能解释为什么用了旧版本。”

“名单异常呢？”

“还解释不了。”

值班工程师说：“旧版本本来就可能有问题。”

周野问：“哪个问题？”

对方没回答。

周野继续往下翻日志。

“还有一件事。”

二十三点四十四，医院侧提交手工重跑请求。

二十三点四十五，任务创建。

二十三点四十六，结果导出。

罗诚说：“就是截图那批。”

“对。”

“请求人是谁？”

“接口账号。”

“人呢？”

“日志不记人，只记账号。”

主任看罗诚。

罗诚已经打开流程记录。

“手工重跑要填申请单。”

他搜时间。

没有。

又搜项目号。

还是没有。

“没单子。”

主任问周野：“你们没有申请单也能重跑？”

周野说：“接口有权限。我们只收到请求，不判断你们内部有没有单。”

“谁给的权限？”

“项目初期配置的。”

“谁批的？”

“这个要查合同和权限表。”

主任没再问。

罗诚在白板上写：

**23:44 手工请求——申请记录缺失。**

周野说：“先别写缺失。”

罗诚停笔。

“为什么？”

“可能在别的系统里。你现在只能写‘当前未找到’。”

主任看了周野一眼。

“行。写‘当前未找到’。”

罗诚改了。

八点四十六，医院那边回电话。

主任开免提。

“昨晚十一点四十多，谁让系统重跑的？”

电话那边很快回答：“我们这儿值班的人。”

“为什么？”

“有一批随访数据晚到，原名单已经有人等着用。”

“谁等着用？”

“随访组。”

“有没有人明确说用哪个模型版本？”

“这跟医院有什么关系？我们只说数据补齐了，重新跑。”

主任没说话。

周野的头像还在会议框里。

他问：“补的数据是什么时间进库的？”

电话那边报了一个时间。

二十三点四十二。

罗诚看白板。

两分钟以后，手工重跑请求发出。

主任问：“截图是谁发出去的？”

“不知道。”

“那批名单谁能看？”

“随访组、项目协调、数据管理员。你们那边也能看。”

“有多少人？”

“这我现在数不出来。”

电话挂断。

会议里没人马上说话。

值班工程师先开口：“所以现在看，流程是医院补数据，然后要求重跑，系统因为回滚用了旧版本。”

主任问：“可以写进九点说明吗？”

周野说：“可以写发生了这些事。”

“因果呢？”

“不能写成‘因为回滚，所以名单异常’。”

“为什么？”

周野把第二批和第三批的输出并排打开。

“因为两批数据不一样。”

“当然不一样，补了数据。”

“所以你现在不知道差异来自版本，还是来自输入。”

主任说：“两个都是旧版本。”

“对。”

“那版本差异怎么查？”

“得拿同一份输入分别跑 `v3.4.2` 和 `v3.5.0`。”

值班工程师插话：“现在？”

周野说：“如果你们要知道版本是不是原因，就现在。”

主任问：“多久？”

“先做小范围，不跑全量。半小时。”

“能保证？”

“不能。”

主任盯着屏幕。

“二十分钟后九点。”

“那九点前只能报已知事实。”

这句话已经有人说过。

这次没人反驳。

罗诚开始整理四项回复。

名单真实：是。

实际使用：医院侧已导出，使用范围待核。

运行版本：第二、第三批确认 `v3.4.2`；第一批实际实例待核。

异常范围：未确定。

他刚准备发送给主任，周野忽然说：“等一下。”

“怎么了？”

“第二批和第三批不是同一个输入快照。”

“刚才知道了。”

“不是这个。”

周野把两个文件的摘要值放大。

“第三批输入里少了一张表。”

主任问：“什么表？”

周野没马上回答。

他点开字段列表。

“人工随访状态。”

罗诚看向第一章那张第六页。

三个月没有随访记录。

低风险。

人工复核：否。

主任把九点回复草稿又拉了回来。

“先别发。”
