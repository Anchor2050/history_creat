# 读者优先的因果密度模型 v1

## 核心原则

这部小说首先是写给读者看的。

每一句话、每一段、每一场戏、每一章都必须回答一个问题：

> **它为什么要存在？**

如果答案只是“更有文学感”“显得真实”“补一点生活气息”“表现人物很复杂”“让文字不那么干”，默认不够。

文学性不能靠无效细节堆出来。真正的密度来自：读者在阅读时不断获得新的事实、新的判断、新的悬念、新的关系变化和新的因果预期。

参考《水浒传》《三国演义》《红楼梦》以及现代强情节历史小说的共同长处：

- 事情先发生；
- 人物因事情显形；
- 每个人都有自己的利益、位置和误判；
- 前面出现的东西会在后面产生后果；
- 细节不是摆设，而是动作、权力、关系或因果的一部分。

## 一、句子存在测试

正文中每个实义句至少承担以下一项功能：

1. **Action**：发生了一个动作，改变了现场状态。
2. **Information**：提供了读者此前不知道、且后面会影响理解的信息。
3. **Pressure**：增加限制、时间压力、风险、代价或冲突。
4. **Character**：通过选择、动作、语气或错误暴露人物，而非旁白总结人格。
5. **Power**：改变谁能决定、谁能拒绝、谁掌握信息、谁承担责任。
6. **Setup**：埋下后面会使用的事实、物件、关系、误会、规则或承诺。
7. **Payoff**：回收此前已经出现的东西，并改变当前局面。
8. **Transition**：让场景、时间或视角转换变得必要且清楚。
9. **Orientation**：提供当前动作不可缺少的空间/时间定位。
10. **Rhythm**：纯节奏句。允许，但稀少；必须服务紧张、停顿、幽默或情绪冲击，不能成为灌水借口。

一个句子如果连续两轮审稿都找不到功能，删除。

如果两个句子承担完全相同的功能，优先保留更具体、更有动作性、更有后果的一个。

## 二、段落状态变化测试

每一段结束时，至少有一个状态变量发生变化：

- 读者知道得更多；
- 某人知道得更多或更少；
- 某人的目标改变；
- 某人的策略改变；
- 风险变大或变小；
- 权力位置改变；
- 关系更近、更远或更不确定；
- 一个假设被证实、削弱或推翻；
- 一个伏笔被建立或回收；
- 场景被迫进入下一步。

如果一段结束后，删掉这一段对人物、因果、悬念和下一步都没有影响，删除或合并。

## 三、场景必须有“动词”

每一场戏必须能用一个动词概括人物正在做什么，例如：

- 查
- 追
- 拒绝
- 说服
- 隐瞒
- 核验
- 争取
- 推责
- 保人
- 切割
- 等待
- 试探
- 交换
- 撤回
- 证明
- 拖延

不能用“了解”“交流”“思考”“感受生活”当主要场景动词。

一个有效场景至少包含：

**目标 → 阻力 → 策略 → 变化 → 残留问题。**

不要求每场戏有高潮，但要求场景前后不相同。

## 四、对话功能测试

每一句对话至少完成一项：

- 给信息；
- 要信息；
- 隐瞒信息；
- 测试对方；
- 改变条件；
- 争夺解释权；
- 争夺决定权；
- 推卸或承担责任；
- 拉近或拉远关系；
- 威胁、安抚、诱导、敷衍、拒绝；
- 暴露误解或价值冲突；
- 形成后续承诺。

警惕：

- 为了“真实”而写的寒暄；
- 连续机灵接话；
- 两个高学历人物轮流说正确的话；
- 旁白已经解释过的内容再让人物说一遍；
- 只为展示知识而存在的专业对话。

## 五、细节必须能被“使用”

细节进入正文后，应至少被使用一次。

可使用方式：

- 触发动作；
- 造成限制；
- 暴露阶层/职业/时代；
- 改变判断；
- 后文回收；
- 成为误会来源；
- 成为证据；
- 成为权力象征；
- 成为人物习惯的可见载体。

禁用型细节：

- 只是因为作者觉得“有画面”；
- 只是为了证明作者观察细；
- 同一类物件反复出现却没有后果；
- 与人物选择、冲突、因果无关的环境陈列。

## 六、伏笔与回收账本

每一个显眼事实、名字、物件、承诺、秘密、异常，都进入 payoff registry。

至少记录：

- 首次出现在哪里；
- 当时读者如何理解；
- 真正作用是什么；
- 最迟应在哪个阶段回收；
- 回收以后改变了什么。

允许红鲱鱼，但红鲱鱼也必须有功能：改变人物判断、误导行动或造成代价。

## 七、章节存在测试

一章至少完成两项：

- 推进中央事件；
- 改变一方立场；
- 引入一个后续会持续作用的角色；
- 回收一个重要伏笔；
- 产生新的不可逆后果；
- 把私人问题与公共事件连接起来；
- 让读者对同一事实形成新的理解；
- 使下一章成为“必须发生”而非“作者想换人”。

章节末尾不要求悬崖，但必须留下因果上的未完成。

## 八、读者问题链

写作时同时维护三层问题：

### 立即问题
读者为什么要读下一页？

### 中程问题
读者为什么要读下三章？

### 长程问题
读者为什么要读完整部小说？

每一章至少回答一个旧问题，同时制造或加深一个新问题。

只提问不回答会疲劳；只回答不留问题会松散。

## 九、反灌水删除规则

出现以下情况优先整段删除：

- 同一个人物特质第三次被同义证明；
- 场景只证明“工作很忙/生活很真实”；
- 描写没有改变任何人的行为；
- 人物把读者已经看懂的意义总结出来；
- 结尾出现主题总结句；
- 对话可以删掉一半而信息、关系、行动完全不变；
- 一段生活细节既不制造节奏反差，也不产生后果；
- 专业知识只证明人物专业，没有进入决策或冲突。

## 十、最终审稿问题

对每句话问：

> 如果删掉它，后面有没有任何东西变得更难理解、更少力量或失去因果？

如果没有，删。

对每一场戏问：

> 如果这场戏不存在，后续人物还会做同样的事吗？

如果会，重写或删。

对每一章问：

> 读者看完以后，世界、人物关系、风险或理解有没有发生变化？

如果没有，这章不存在。
