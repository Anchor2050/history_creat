# 读者审阅：前四章的剧情连接缺口（pass 01）

状态：`adaptation_only` 非正典读者意见。提出于 2026-10-11，来源为人类读者审阅（**不是**独立模型审阅），经仓库交接通道（bus）转达给下一驱动者。

## 意见

前四章（`ch01`–`ch04`）之间**没有因果剧情连接**。并排阅读时，它们像四篇自足短文，而不像同一部作品连续的四章。

## 证据

- **Ch1 周野**：做复现包、与许航微信 —— 自足，不推动任何后续事件。
- **Ch2 宋楠群像**：一次周末出行 —— 与 Ch1 无因果关系，只是许航等人在场。
- **Ch3 罗成**：找孙洁问辅导员岗、改简历 —— 独立于前两章。
- **Ch4 唐雨**：换实现跑对照、和许航对图 —— 独立于前三章。
- 四章**没有共同触发事件、没有跨章后果累积、没有悬念→兑现**。
- 四章中三章（1/3/4）都依赖文档/代码/材料类工作场景，**语域同质**，进一步削弱差异感。

## 设计意图 vs 执行缺口

- **意图**：架构规则写明 `Core six are weakly connected ensemble peers, not a permanent six-person team`，用 braid（编织镜像）、人物重叠、长期 hero arc 替代传统因果剧情链。
- **缺口**：braid 与长期弧线目前**只存在于架构文档**（`substory-graph-v1.json`、`hero-arc-negative-space-matrix-v1.json`），正文没有可感知的抓手。
- **现有接线**：`braid:first-pricing` → ch01/ch03/ch04；`braid:ordinary-network` → ch02；许航横跨 ch01/ch02/ch04。

## 严重度

`structural` —— 影响读者连贯性与开篇序列，牵涉 Chapter5 及其后的推进方式。

## 候选处理方案（需择一）

1. **选项 A（低成本）**：保留弱连接，增加可感知编织。在正文里插入可复述的呼应物 / 共同来源 / 被复述的一句话，让同一 braid 的章节能被读者隐隐串起，不引入强因果主线。
2. **选项 B（高成本）**：升一格，加一条真正因果主线。给开篇一个共同触发情境（答辩季 / 招聘季 / 集体迁移等），让四章成为同一根线上的四个岔口。**风险**：可能违反 weakly-connected ensemble 规则，需明确改规则或标注例外。
3. **选项 C（中等）**：维持现状，后段选择性聚拢。前四章作为独立引入，从某一章起让 braid 线索开始收拢，Chapter5 起接入可见连接。

## 硬约束

- 推进 Chapter5 **之前**必须至少选定一个选项，并在 `adaptation-head-v1.json` 的 `open_reviews` 中记录结论。
- 不得用作者旁白 / 对话直接宣告主题来伪造连接。
- 不得把 braid 变成章节标签或论文式小标题。
- 不得为了连接而牺牲 negative-space 的留白原则。
