# Probe P2-04：能不能用

> disposable adaptation-only prose。历史锚点：2034–2035 宋楠第二岗位学习速度中等，但判断责任增加、生活 bundle 更可持续。马晴为改编层过客角色，已通过 reverse plausibility audit；具体项目、会议、姓名与对白不回写 ledger。

马晴把 PPT 翻到第十二页，停住。

“这一页我下午得拿去跟医学团队过。”

宋楠看了一眼：“这版不行。”

“哪里不行？”

“你把‘目前没看到明显差异’改成‘两组无差异’了。”

“他们就想知道有没有差异。”

“那答案就是现在不知道。”

马晴靠到椅背上，闭了闭眼。

会议室的空调有点冷。宋楠把电脑往自己这边拉了一点，打开结果表。

“你看，”她说，“主分析这边是这样，但这个亚组样本太少。现在只能说在现有数据里没看到稳定信号，不能说两组一样。”

“我知道统计上不能这么说。”马晴说，“问题是下午那帮人不会问你‘有没有稳定信号’，他们会问：那到底还要不要往下做？”

“这不是一回事。”

“对他们是一回事。”

宋楠没接。

马晴把鼠标拿回来，把那句话改成：

> 现有分析未支持明确组间差异。

“这样呢？”

“还是容易被听成没差异。”

“那你写。”

宋楠盯着屏幕。

她删掉整句，重新打：

> 当前数据不足以支持稳定的组间判断；若本次决策需要区分两组，建议补充 X 信息后再判断。

马晴看完：“太长。”

“已经很短了。”

“你没见过他们一页 PPT 上最多看几行字。”

宋楠抬头：“那我不能为了他们不看字，把意思改了。”

马晴也抬头。

两个人安静了几秒。

“我不是让你改意思。”马晴说，“我是让你告诉我，今天下午到底能做什么。”

“我刚才说了，补 X 信息。”

“补 X 要三周。”

“那就三周以后再做这个判断。”

“项目不是只等这个判断。”

宋楠把手从键盘上拿开。

“那你们下午到底要决定什么？”

马晴愣了一下。

“什么叫到底决定什么？”

“如果只是决定下一步先做不做 Y，那不需要把两组说成一样。你告诉我真正的决策，我可以给你现在能支持到哪。”

马晴看着她，没说话。

过了一会儿，她把前面两页翻回来。

“下午有两个问题。”她说，“第一个，Y 要不要继续；第二个，要不要现在就按两组分开准备后面的资源。”

“那第二个现在别做。”

“第一个呢？”

“第一个可以做。但理由不能用这页。”

“用哪页？”

宋楠往前翻到第九页：“用这个。这个结果跟两组差异没关系。”

马晴把椅子拉近了一点。

两个人重新排了三页。

第一页只写今天能决定的事；第二页写暂时不能决定的事；第三页列触发下一轮分析的条件。

马晴看了一遍，说：“行，这个我能讲。”

宋楠说：“第三页别删。”

“我没说要删。”

“你刚才那个表情就是想删。”

“我刚才那个表情是觉得三页太多。”

“那现在呢？”

“现在还是觉得多。”

宋楠笑了一下。

马晴把文件另存了一版，文件名后面加了两个字：下午。

临出会议室，她回头问：“你下午有空吗？要不你自己来讲？”

宋楠说：“你先讲。真问到统计边界再叫我。”

“行。”

门关上以后，宋楠把原来的第十二页删了。
