# Probe P2-02：招聘启事

> disposable adaptation-only prose。历史锚点：2027-04-19 罗诚拿公开学生事务岗位说明向孙洁请教；孙洁把职责翻成真实日常，并指出直接学生工作证据偏少，明确不判断“能不能进”也不提供推荐性补偿。办公室细节与对白为改编细节。

孙洁把招聘启事往下滑了半页。

“这一条，学生谈话。”她说，“你做过吗？”

罗诚想了一会儿：“带过本科生答疑，助教的时候也处理过一些学生的问题。”

“多长时间？”

“一学期。”

“固定带班？”

“没有。”

孙洁在纸上点了一下，没有说行，也没有说不行。

罗诚坐在她对面。桌上有两摞材料，一摞贴了黄色便签，一摞贴了蓝色便签。刚才进门的时候，孙洁让他等了七八分钟，先把一个毕业手续的问题回完。

“那活动组织呢？”她又问。

“学院有活动我帮过。”

“你负责哪块？”

“统计人，排名单，现场也在。”

“这个可以写。但别写成你负责整个活动。”

罗诚笑了一下：“我也没那么敢写。”

孙洁抬头：“有人敢。”

她接着往下看。

岗位要求里有一行“具有较强的组织协调、沟通表达和学生工作能力”。罗诚把这一行用指甲压住。

“这种话是不是谁都能写？”

“招聘启事里是。”孙洁说，“材料里不是。”

“那博士优先呢？”

“博士就是博士。”

“我知道，我是说——”罗诚停了一下，“如果学生工作经历少一点，博士会不会能补一点？”

孙洁没马上答。她先把手机翻过来，看了一眼时间。

“我只能跟你说我理解这个岗位平时在干什么。”她说，“谁能补谁，补多少，我不知道。就算知道，我也不该跟你讲。”

“我没问内部线。”

“我知道。”

这句“我知道”说得很平，反而让罗诚有点坐不住。

孙洁把招聘启事转过来，拿笔在几个词下面划线：材料审核、值班、谈话、活动、跨部门协调。

“你做流程跟进，能写。你做记录，能写。你跟人解释复杂东西，也能写。”她说，“但学生工作这块，你现在有多少就写多少。别把博士六年自动换算成六年学生工作。”

罗诚盯着那几道线。

“听起来我这种人就挺尴尬。”

“哪种人？”

“书读太久了，能说的都像训练，不像经历。”

孙洁把笔帽扣上：“这个我没法替你解决。”

罗诚没接话。

外面有人敲门，问一份表到底交纸质还是电子版。孙洁说都要，纸质交到下午四点，电子版发邮箱。那人说“群里不是说电子版吗”，孙洁起身去找昨天发的通知。

罗诚低头又把招聘启事看了一遍。

等她回来，他把纸折了一下，说：“我还是投。”

“可以。”

“你这个‘可以’是说我能进，还是说我可以投？”

孙洁看了他一眼：“你说呢？”

罗诚笑了：“行。”

他把那张纸塞进文件袋，出门前又回头问：“材料审核这项，我写博士期间帮课题组核材料，算不算？”

“写你具体核过什么。”孙洁说，“别写‘具备材料审核能力’。”

“知道了。”

“门带一下。”
