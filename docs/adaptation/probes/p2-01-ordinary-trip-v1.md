# Probe P2-01：短途旅行

> disposable adaptation-only prose。历史锚点：2026-07-23/24 短途活动，陈岚明确介绍宋楠与许航认识；职业话题零散，返程有大量普通生活聊天。地点、交通、饭店、动作和具体对白为改编细节，不回写 ledger。

车开出城以后，宋楠才发现自己带错了充电线。

她把包翻了两遍，最后从侧袋里拎出一根 Type-C，盯了三秒，问前排：“谁还活在 Lightning 时代？”

林静回头：“我。”

“救命。”

“二十块一天。”

宋楠把手一伸：“回来请你喝奶茶。”

“那行。”

唐雨坐在靠窗那边，耳机只戴了一只。她刚把手机亮度调低，陈岚就从后面拍了拍许航的椅背。

“许航，”她说，“这是宋楠。上次我跟你提过，她最近也在折腾版本、复跑这些东西。”

宋楠把充电线接上，抬头看了许航一眼：“我属于被折腾的那个。”

许航笑了一下：“那比较正常。”

“你们做东西真会留失败记录吗？”

“看什么东西。”许航说，“临时试的不会全留。关键步骤我会留，尤其是以后可能忘掉为什么这么做的。”

宋楠点点头，没继续问。车正在过收费站，司机踩了一脚刹车，后排有人把一袋薯片掉到了地上。

午饭订的是景区边上一家农家菜。桌子很大，转盘有点涩。林静夹菜夹到一半，盘子被宋楠顺手转走了。

“哎。”

“啊？”宋楠又转回来，“你先你先。”

林静夹完排骨：“你这个人吃饭也赶项目。”

“我饿。”

唐雨问老板能不能少放辣，老板说已经做了。她没再说什么，拿纸巾擦了擦碗边。

席间有人聊到最近在做什么。宋楠说自己开始把分析过程写得更像别人能接手的东西，许航问她有没有固定输入和关键输出。两个人说了四五分钟，后来话题就被岔开了。

陈岚问：“下午爬不爬？”

林静：“我不爬。”

“昨天不是说爬？”

“昨天没有今天这么热。”

宋楠说：“那我也不爬。”

唐雨抬头：“你刚才在车上不是还说来都来了？”

“现在我来过了。”

下午最后分成两拨。许航和唐雨去了山脚那条短线，陈岚跟着走了一段。宋楠、林静在镇上找了家有空调的店，点了两杯冰饮，坐了快两个小时。

她们聊了租房。林静说楼下便利店最近换了老板，晚上十一点以后不卖关东煮了。宋楠说自己那边洗衣机甩干的时候会往前走，她拿一箱矿泉水抵着。

“房东不管？”

“他说能洗就行。”

林静笑：“那确实能洗。”

第二天回程，大家比来的时候安静。宋楠把借来的充电线卷好，递回去。

林静接过去看了一眼：“奶茶呢？”

“欠着。”

“记账。”

“你们搞统计的怎么都这样。”

“你也是。”

宋楠愣了一下：“哦，对。”

车里有人笑了两声，之后又没人说话了。
