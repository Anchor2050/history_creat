# Probe P3-02 v2：马晴的上午

> disposable adaptation-only prose。v2 只做删减型修订：减少心理解释、缩短漂亮闭环、保留疲惫会议中的打断和不顺。

马晴九点零七分进会议室，医学部已经到了三个人。

她把电脑放下。

“昨天那个版本谁发的？”

坐最里面的人说：“产品那边。”

“版本号呢？”

没人答。

有人低头翻群消息。马晴等了几秒，先把自己的文件打开。

宋楠昨晚十一点多发来的分析在第二页开始分层。

九点二十，宋楠上线。

马晴把屏幕切过去。

“我先问一个。A 组下周那个方案，现在推不推？”

宋楠说：“整体我不建议推。”

“原因一句话。”

“有一层方向不稳。平均以后看不出来。”

医学部那边有人问：“不稳到什么程度？”

宋楠停了一下。

“现在这批数据我不想给一个更硬的词。”

马晴说：“那我们下午怎么讲？”

“就讲不能整体推。”

“后面呢？”

宋楠把页面往下翻：“两个预设条件下还可以。第三个证据不够，下一轮补第三个。”

马晴看着第二页。

“这句话放第一页。”

“第一页我要交代为什么分层。”

“放后面。”

“后面他们不一定看。”

“第一页那三行方法他们也不会看。”

宋楠没接。

会议室里有人咳了一声。

马晴把那三句话复制到第一页，改了两处字。

宋楠说：“第二句加‘当前数据范围内’。”

马晴加上。

“第三个别写无效。”

“我没写。”

“你刚才口头说的——”

门被推开，一个同事探头进来：“马晴，十点半那个会提前十分钟。”

马晴抬头：“知道了。”

她再看屏幕。

“先这样。你把附页补完整。”

宋楠说：“行。”

医学部的人又问了一遍：“所以今天结论就是先不整体改？”

马晴说：“先不整体改。第三类补数据。”

“那两类呢？”

马晴看了宋楠一眼。

宋楠说：“按现在的数据，可以继续原方案，不加码。”

“好。”

九点五十八，会议散了。

马晴回工位以后才发现自己刚才把一个旧版本留在了共享目录。

她删掉旧文件，重新发链接。

宋楠私聊过来：

> 第一页我补了限定词。

马晴回：

> 收到。

十点十六，她抱着电脑去下一间会议室。
