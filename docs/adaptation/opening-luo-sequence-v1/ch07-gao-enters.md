# 第七章：你真回去啊

> adaptation-only disposable prose。历史锚点：2028-11-03 周野、高原、罗诚三位老同学视频通话；高原说明自己已接受家乡地级市公务员岗位，罗诚分享研究支持岗体验，周野更多询问租房与通勤，没有把通话变成职业排名。本文只截取罗诚—高原为主的一段，周野延后上线，不在本章展开。

十一月初，罗诚下班回到出租屋，外卖刚送到。

塑料袋里一份米饭，一份青椒肉丝。

米饭盒盖子压得有点歪，汤汁漏出来，沾在筷子包装上。

他拿纸擦到一半，手机响了。

高原发来视频邀请。

罗诚看了一眼桌上的饭，接了。

画面先是天花板。

“你手机拿反了。”

“等一下。”

高原的脸终于出来。

背景是宿舍。

桌上堆着书，旁边一个纸箱已经封了一半。

罗诚把手机靠在水杯上。

“你收拾东西？”

“嗯。”

“毕业了？”

“还没彻底弄完。”

“那你装什么？”

高原低头看了一眼纸箱。

“先寄一批回去。”

罗诚拆筷子。

“回哪？”

高原看着屏幕。

“回家。”

“放东西？”

“不是。”

停了半秒。

“工作也回去。”

罗诚筷子没夹稳，一块青椒掉回盒里。

“你真回去啊？”

“嗯。”

“考上了？”

“嗯。”

罗诚坐直一点。

“什么时候的事？”

“前阵子。”

“你怎么现在才说？”

“结果定了再说。”

“公务员？”

“对。”

“家里那个市？”

“嗯。”

罗诚看着他。

高原也没说话。

“你这人真能憋。”

“还好。”

“工资多少？”

高原说了个数。

罗诚嚼东西的动作慢了一下。

“比我还低。”

“正常。”

“你还这么平静？”

“房租便宜。”

“住家里？”

“不一定。先看通勤。”

“你家到单位多久？”

“三四十分钟吧。”

“开车？”

“公交也差不多。”

罗诚扒了一口饭。

“那确实省。”

高原笑了一下。

“你现在也会算这些了。”

“我每个月交两千四房租，当然会算。”

“你那边怎么样？”

“什么怎么样？”

“新工作。”

罗诚想了一下。

“比辅导员适合一点。”

高原说：“一点？”

“先说一点。说多了容易打脸。”

“你不是已经干几个月了？”

“几个月更不敢说。”

高原笑。

罗诚把手机往旁边推了推，让充电线够得到。

“你呢？”

“什么我？”

“你准备公务员准备那么久，真拿到了，啥感觉？”

高原没有马上答。

他把桌上一摞书往箱子里放。

第一本是行测题。

第二本也是。

第三本是一本概率论教材。

他把概率论那本抽出来，放回桌上。

“没什么特别的。”

“扯。”

“真的。”

“你第一轮没进面试线的时候可不是这样。”

高原手停了一下。

“那时候觉得，好像一年都白弄了。”

“现在呢？”

“现在觉得也就这样。”

“你开始装了。”

高原笑了一声。

“我主要是在想，回去以后会不会太慢。”

“什么太慢？”

“城市小。工作也不知道具体什么样。以后想换，选择少。”

罗诚没马上接。

屏幕里，高原把一本申论笔记塞进纸箱。

“那你还回？”

“回。”

“为什么？”

高原抬头。

“我本来就想回。”

罗诚看着他。

“就这？”

“离家近，房子便宜，工作稳。考试之前我也是这么想的。”

“考两年以后呢？”

高原没说话。

罗诚问：“你现在到底是想回，还是考了两年舍不得不回？”

话说完，他自己先觉得有点重。

高原倒没生气。

他把胶带拉出来一截，没剪。

“都有吧。”

“多少？”

“不知道。”

罗诚点点头。

“那还行。”

“什么还行？”

“你没给我讲大道理。”

高原笑。

“我能有什么大道理。”

“你以前挺能讲的。稳定、服务社会、长期发展。”

“面试用。”

两个人都笑了一下。

罗诚夹了块肉。

“那你啥时候走？”

“年底前后吧。具体看手续。”

“到了给我发照片。”

“发什么？”

“单位门口。”

“神经。”

“看看你到底去了哪。”

高原低头继续收书。

过了一会儿，他问：“你那边现在还天天催材料吗？”

“天天。”

“你烦吗？”

罗诚想了想。

“有时候烦。”

“后悔吗？”

“目前没有。”

“那就行。”

“你看，你又开始总结了。”

高原没理他。

手机上方弹出一条提示：

**周野加入通话。**

罗诚看了一眼。

“来了一个已经上班一年的人。”

高原说：“你别一上来就问工资。”

“我什么时候——”

画面切成了三格。

第三格还黑着。

罗诚把饭盒往自己这边拉了一点。

“喂？听得见吗？”

黑屏里传来一声：

“听得见，地铁里。”

罗诚没问别的。

他继续吃饭。
