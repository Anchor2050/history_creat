# 第二章：你举一个例子

> adaptation-only disposable prose。历史锚点：2027 年罗诚进入学生事务公开招聘流程；两条相关岗位最终都未录用。具体首轮面试问题、候场细节和结果通知方式为改编层虚构，不给失败预设单一原因。

面试通知来得比罗诚预想得早。

上午九点四十二分。

他刚从食堂出来，手机震了一下。

邮件标题只有六个字：

**资格审核通过通知。**

他站在食堂门口，把邮件从头看到尾。

面试时间在三天后。

要求带身份证、学历证明、报名表和一份个人陈述。

最后一行写：

**请提前三十分钟到场。**

罗诚先截了图。

手指停在微信上几秒，又退了出来。

没发给孙洁。

那天晚上，他把个人陈述改到一点多。

第一版开头是：

> 本人具有扎实的学术训练与较强的组织协调能力——

他盯了一会儿，全删了。

第二版写得具体得多。

助教答疑。

会议报名。

名单核对。

临时换教室。

跟财务确认材料。

帮老师催过附件。

写到最后，看起来又不像一份很有气势的材料。

罗诚靠在椅背上看了半天。

还是没把“组织协调能力”加回来。

面试那天，下雨。

等候室里坐着八个人。

罗诚来得早，领了号码牌，坐在最后一排。

前面一个女生在背材料。

声音压得很低。

“坚持立德树人根本任务……”

背到一半停下来，又从头开始。

右边一个男生把手机横过来，一页一页翻学校官网。

罗诚也打开了自己准备的笔记。

第一页写岗位职责。

第二页写自己的经历。

第三页只有一行：

**不会的别硬编。**

这句话是他自己写的。

十点二十六分，工作人员出来叫号。

“七号。”

罗诚站起来。

进去以后，桌后坐着三个人。

中间的人先让他做自我介绍。

罗诚讲了两分钟。

博士。

数学。

助教。

材料和会务。

讲到“学生工作”时，他自己慢了一点。

左边的人抬头。

“你说自己有跟学生沟通的经验。”

“主要是助教和课程答疑。”

“有没有处理过学生之间的冲突？”

“没有正式处理过。”

“宿舍矛盾呢？”

“没有。”

“学生情绪危机？”

“也没有。”

中间的人看了一眼简历。

“那你为什么觉得自己适合这个岗位？”

罗诚没有马上说。

这个问题他准备过。

稳定。

高校环境。

喜欢跟人打交道。

长期工作。

博士优先。

这些词排得很整齐。

可真坐到这里以后，说哪个都像太轻。

“我做长期跟进比较有耐心。”他说。

“举个例子。”

“博士期间有一项合作材料拖了很久，中间换过版本，也缺过附件，我负责把节点和缺的东西一直跟下去。”

“学生工作。”

罗诚停了。

“学生工作里，我没有完全对应的例子。”

右边的人第一次开口。

“如果一个学生连续三天不回消息，你怎么办？”

“先确认有没有别的联系渠道。”

“没有。”

“找同学？”

“如果涉及隐私，我会先看学校有没有程序规定——”

“现在先别讲程序。你是辅导员。”

罗诚顿了一下。

“那我会先确认安全。”

“怎么确认？”

“联系宿舍。”

“宿舍没人知道。”

“联系家长？”

“学生明确说不希望联系家长。”

罗诚没再往下接。

中间的人说：“你可以想一会儿。”

屋里安静下来。

窗户没关严，雨声从缝里进来。

罗诚看着桌角那瓶没拆封的矿泉水。

“我不知道你们这里的具体处置规范。”他说，“如果是现实情况，我不会自己拍脑袋决定下一步。我会先找值班老师或者负责人确认危机等级和程序。”

左边的人问：“所以你第一反应还是找程序？”

“可能是。”

“为什么？”

罗诚想了想。

“因为我怕自己判断错。”

右边的人低头记了几笔。

后面的问题简单些。

组织活动遇到场地临时取消怎么办。

材料截止前有人迟交怎么办。

两个部门互相等对方确认怎么办。

这些他答得顺很多。

“先确认谁能决定。”

“把缺口列出来。”

“能先交的先交。”

“留记录。”

到最后，中间的人又问了一句。

“如果录用，你觉得自己最需要补什么？”

罗诚说：“直接学生工作经验。”

这次三个人都没有再问。

出来以后，雨已经小了。

等候室还剩三个人。

刚才背材料的女生已经不在。

罗诚把号码牌交给工作人员，下楼。

走到一楼大厅，他才发现自己手心一直是湿的。

不是雨。

一周后，学校官网公示进入下一环节名单。

罗诚把页面往下翻。

七个人。

没有他。

他重新刷新了一次。

还是七个人。

手机就在旁边。

这回他给孙洁发了消息。

> 没进。

孙洁过了四十多分钟才回：

> 嗯。

又过了一会儿：

> 你自己觉得哪块答得最虚？

罗诚看着这句话。

没回。

晚上十一点多，他重新打开面试笔记。

第三页那句：

**不会的别硬编。**

还在。

他在下面又加了一行：

**但不会的，面试官真的会问。**

写完他自己笑了一下。

第二天中午，他又在招聘网站上看到了一条高校学生事务岗位。

职责很像。

学历要求也很像。

罗诚看了很久。

没有马上关掉页面。
