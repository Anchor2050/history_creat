# 第二章：你举一个例子（v2）

> adaptation-only disposable prose。删减版。保留第一次面试、具体经验缺口和落选，不让整章变成问答题。

面试通知来得很早。

上午九点四十二分，罗诚刚从食堂出来，手机震了一下。

**资格审核通过通知。**

三天后面试。

要求带身份证、学历证明、报名表和一份个人陈述。

晚上，他把个人陈述改到一点多。

第一版开头是：

> 本人具有扎实的学术训练与较强的组织协调能力——

他盯了一会儿，全删了。

第二版只剩做过的事情。

助教答疑。

会议报名。

名单核对。

临时换教室。

跟财务确认材料。

写到最后，气势小了很多。

他没把那些形容词加回来。

面试那天下雨。

等候室里坐着八个人。

前面有人小声背材料，背到一半又从头开始。

罗诚打开自己的笔记。

第一页是岗位职责。

第二页是自己的经历。

第三页只有一句：

**不会的别硬编。**

轮到他以后，中间的人先让他自我介绍。

博士。

数学。

助教。

材料和会务。

讲到学生工作时，他慢了一点。

左边的人问：“处理过学生冲突吗？”

“没有正式处理过。”

“情绪危机？”

“没有。”

“那你为什么觉得自己适合？”

罗诚准备过这个问题。

稳定。

高校。

喜欢跟人打交道。

博士优先。

真坐在这里以后，哪个词都显得轻。

“我做长期跟进比较有耐心。”

“举个例子。”

罗诚讲了一项拖了很久的合作材料，版本换过，附件缺过，他负责一直跟到最后。

面试官听完，只说：“这是流程。”

“对。”

“学生工作呢？”

罗诚停住。

“没有完全对应的例子。”

右边的人递来一个情境。

学生三天不回消息。

宿舍也没人知道去了哪。

罗诚第一反应是确认学校程序。

对方追问：“如果现在就要你决定呢？”

屋里安静了一会儿。

窗户没关严，雨声从缝里进来。

“我会先确认安全，再找值班老师或负责人。”罗诚说。

“你还是在找程序。”

“可能是。”

“为什么？”

“怕自己判断错。”

后面的问题，他顺很多。

活动临时没场地。

材料迟交。

两个部门互相等确认。

这些他都能说出具体做法。

最后，中间的人问：“如果录用，你最需要补什么？”

罗诚说：“直接学生工作经验。”

没人再追问。

一周后，学校官网公示进入下一环节名单。

七个人。

没有他。

罗诚刷新了一次。

还是七个。

他给孙洁发：

> 没进。

四十多分钟以后，孙洁回：

> 你自己觉得哪块最虚？

罗诚没回。

晚上，他重新打开面试笔记。

第三页那句还在：

**不会的别硬编。**

他在下面补了一句：

**不会的，真的会被问到。**

第二天中午，招聘网站又推了一条高校学生事务岗。

罗诚点开。

看完以后，没有马上关掉。
