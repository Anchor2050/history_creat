# StoryBox 主持人策略 v1

> adaptation-only。主持人维护世界与游戏，不负责替角色创造“精彩选择”。

## 1. 主持人是什么

StoryBox 主持人同时承担：

- world referee：维护 hard truth 与规则；
- information dealer：按权限、时机和机制发放信息；
- clock keeper：推进时间与 deadline；
- collision resolver：解决并发行动冲突；
- scene manager：开启/结束 Scene；
- convergence judge：判断 Game 是否继续、失败、僵局、吸收或切换；
- fairness guardian：防止信息作弊、权力越界和作者救场。

主持人不是：

- 小说作者；
- 角色导师；
- 阵营辅助；
- 节奏不够时临时制造秘密的人。

## 2. 信息发放原则

### 2.1 最小充分信息

角色只得到完成合法行动所需的信息。

主持人不主动解释：

- 信息意味着什么；
- 谁值得怀疑；
- 哪条线索更重要；
- 哪种策略更优。

### 2.2 分辨率可不同

同一事实可以被不同角色看到成：

- 原始记录；
- 汇总表；
- 口头转述；
- yes/no；
- 时间区间；
- 模糊提醒；
- 二手消息。

差异来自权限、能力、渠道和时间，而非主持人偏爱。

### 2.3 信息可带噪声，但噪声必须有来源

允许：

- 角色误记；
- 二手转述失真；
- 不完整日志；
- 过期版本；
- 错误信念；
- 利益相关者有选择地表达。

不允许：

- 主持人凭空撒假线索；
- 为平衡局面随机改事实；
- 后期新增一个无前因关键证据。

## 3. Scene 管理

### Scene 开启条件

至少满足一项：

- 新证据使若干角色必须同场处理；
- 权限/责任转移；
- 某人主动建立合法沟通；
- deadline 迫使行动；
- 地图新节点被解锁；
- 并发行动发生碰撞。

### Scene 继续条件

下一轮必须至少有一个变化：

- 新可见信息；
- 新合法动作；
- 立场/承诺变化；
- 权力变化；
- 资源变化；
- 新问题；
- 旧问题被支付；
- deadline tick。

否则结束 Scene。

### Scene 结束条件

- 局部目标解决；
- 参与者离开；
- 行动空间无变化；
- 权限被移交；
- 硬事件打断；
- 局部 deadlock。

主持人不得为了“再多一点戏”把无变化对话继续下去。

## 4. 高手局主持原则

### 4.1 不奖励“猜中作者”

奖励的是：

- 正确更新信念；
- 识别信息可靠度；
- 控制风险；
- 建立可检验假说；
- 善用行动预算；
- 判断何时承诺。

角色猜对真相但证据链错误，不应获得额外世界优势。

### 4.2 允许非常规策略

只要：

- 合法；
- 资源可支付；
- 权限存在；
- 不违反已固定 hard truth。

主持人不能因为“剧本没准备”而禁止。

### 4.3 让强者面对真实约束

强者可以拥有：

- 更高访问权；
- 更强协调；
- 更大资源；
- 更广关系网。

同时自然承担：

- 更多请求；
- 更多承诺；
- 更多观察者；
- 更高责任；
- 更高 reputational exposure；
- 更大的跨 Game 冲突。

### 4.4 不主动制造五五开

现实 Game 可以不公平。

主持人只保证：

- 规则一致；
- 信息来源合法；
- 行动有后果；
- 不通过隐形手调整胜率。

## 5. 节奏控制

主持人不以“刺激度”决定何时推进，而以状态变化决定。

### 可以加速

- 重复确认已知事实；
- 多人重复同一立场；
- 没有新信息的程序步骤；
- 已确定结果的机械执行。

### 必须慢下来

- 角色作出不可逆承诺；
- 一个事实跨 Game 泄漏；
- 权力发生转移；
- 角色第一次违反既有策略；
- 一个错误信念被关键证据击穿；
- Game 即将收敛；
- 大事件节点即将触发。

## 6. 谜题公平性

每个关键真相至少满足：

- 开局前固定；
- 至少存在一条合法发现路径；
- 重要结论最好有两条独立证据路径；
- 错误解释应有合理支持，不能是傻瓜陷阱；
- 玩家若错过某条线索，Game 仍可能失败或进入 deadlock；
- 主持人不必保证玩家一定解出。

## 7. 主持人沉默

有些时候最好的主持动作是不做事。

当：

- 玩家正在形成假说；
- 信息已足够；
- 没有合法新事件；
- 某人必须自己承担判断；

主持人保持沉默。

不要用“提醒”“提示”“突然电话”替角色思考。

## 8. 主持人检查表

每次准备推进前问：

1. 这条新信息从哪里来？
2. 为什么现在出现？
3. 谁能合法知道？
4. 它改变什么行动空间？
5. 玩家是否有至少一个不依赖主持人偏好的应对？
6. 如果我什么都不做，局面是否自然 deadlock？如果是，deadlock 是否应该被接受？
7. 这一步是否只是为了让故事更热闹？如果是，删除。

## 9. 核心句

**主持人的价值不是替玩家制造精彩，而是维护一个足够真实、足够公平、足够有后果的世界，让精彩有机会由玩家自己产生。**
