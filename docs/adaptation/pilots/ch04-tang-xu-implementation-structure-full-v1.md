# Full Pilot：换一种实现以后 v1

> disposable adaptation-only full chapter。历史锚点：2027-05-28/29 唐雨与许航进行有限验证审阅；预先选定的结构里有两个失效现象重复出现，但换一种实现后其中一个明显减弱。两人只将实现敏感性与结构性失效拆开，未形成理论结论。具体办公室、图表、代码细节、饮食、组会时间和对白均为改编层细节，不回写历史 ledger。

唐雨把四张图打印出来的时候，第四张颜色偏了一点。

打印机把蓝色打成了灰紫。

她站在机器旁边看了几秒，又重新打了一份。

第二份还是一样。

她把两份都拿走了。

许航到的时候，她已经把图按两排贴在白板上。

第一排是原来的实现，第二排是她前一天换的实现。每排四张。

“先看第二个和第四个。”

许航把包放到椅子上。

“别的呢？”

“先不管。”

“那我先看你让我看的。”

唐雨把第二张和第四张各圈了一下。

“第二个，五组种子都在。样本量加倍也在。”

许航站近了一点。

“第四个？”

“原来那版也在。”

“下面这排呢？”

唐雨没回答，抬手指了指第四张。

第二排的第四张几乎贴回去了。

许航看了一会儿。

“差挺多。”

“嗯。”

“你换了什么？”

“中间那一步。原来我自己写的，下面这版换成现成包。目标一样。”

“参数一样？”

“能对的都对了。”

“‘能对的’是什么意思？”

唐雨把电脑转过去。

“你自己看。”

许航坐下来。

代码窗口开着两个版本。唐雨已经把几处参数用注释标出来了。

许航先看输入，又去看停止条件。

“这个默认容差多少？”

唐雨说：“文档里有。”

“多少？”

她打开帮助页。

看见数字以后没说话。

许航问：“你原来那版呢？”

“严一点。”

“严多少？”

唐雨切回自己的函数。

许航算了一下。

“不是一点。”

“我知道。”

“你刚知道吧。”

唐雨转头看他。

“你是来查我还是来看问题？”

“都一样。问题在你代码里。”

她没接。

许航又往下翻。

日志文件只有一半。

“这后面怎么没退出状态？”

“机器断过，我重跑了。”

“重跑以后呢？”

“结果在。”

“我看见结果了。中间呢？”

唐雨把鼠标从他手边拿回来。

“当时没记。”

许航点了一下头。

她说：“你别点头。”

“我没说什么。”

“你这个点头比说话烦。”

许航靠回椅背。

“那不点。”

隔壁办公室有人推门进来，问有没有订书机。

唐雨指了指窗台。

那人拿走以后，门没关严。走廊里的打印机一直响。

唐雨起身把门带上。

回来以后，她重新指了指白板上的第二张。

“这个没变。”

“嗯。”

“换实现也没变。”

“目前是。”

“所以至少有一个东西是稳的。”

许航看着第二张图。

“至少你现在这两套实现里，它没明显变。”

“你非要加这么长的限定吗？”

“要。”

唐雨笑了一下，不太像笑。

“那论文以后都让你写。”

“我不写你那部分。”

她把红笔盖扣上。

“我本来想把这两个一起放进主问题。”

许航说：“现在别一起。”

“为什么不能把第四个写成实现敏感？”

“可以写观察。”

“主问题呢？”

“先不知道。”

“敏感本身就可能有东西。”

“也可能没东西。”

唐雨看着他。

许航把第四张图从白板上揭下来，放到桌上。

“你两套实现都还没完全对齐。”

“核心步骤一样。”

“什么叫核心？”

“目标函数、更新顺序、初始化——”

“停止条件不算？”

唐雨没说话。

许航把纸又放回桌面。

“你先别急着给它名字。”

“我没急。”

“行。”

两个人开始一项一项对。

输入一样。

初始化一样。

一个版本对异常值做了截断，另一个也做了，只是位置不同。

停止条件不一样。

缺失值处理在这组模拟里没触发。

随机种子的位置也不一样。

唐雨说：“这个我昨天已经改过了。”

“改完跑了吗？”

“跑了两组。”

“全矩阵呢？”

“没跑完。”

许航没再问。

十二点半以后，两个人去楼下买饭。

食堂最里面那排窗口已经收了一半。

唐雨端了碗面，许航拿了盒饭。

坐下以后没人先提刚才的图。

许航吃到一半问：“你下午还有事吗？”

“三点组会。”

“那剩下这点时间跑不了全的。”

“跑小的。”

“可以。”

唐雨搅了两下碗里的面。

“第四个最开始是最明显的。”

许航抬头。

“嗯。”

“如果它是真的，后面那条线很顺。”

许航又低下头吃饭。

过了一会儿他说：“那你先别让后面那条线替前面做决定。”

唐雨没说话。

旁边桌有人把汤洒了，椅子往后拖了一下。

她抽了张纸，把碗边擦了擦。

下午回去，他们只跑了缩小版。

停止条件调齐以后，第四个现象比原来强一点，但还是远弱于第一套实现。

第二个基本没动。

许航把两张图来回切。

唐雨问：“现在呢？”

“现在还是两个问题。”

“第四个算什么？”

“先算实现敏感。”

“只是实现敏感？”

“你还想算什么？”

唐雨把椅子往后推了一点。

“我问的是，值不值得继续。”

许航说：“值得查。”

“查跟做不是一回事。”

“本来就不是一回事。”

她看了一眼时间。

两点四十二。

唐雨打开下午汇报的第一页。

标题写着：

**两个稳定失效现象**

她把“稳定”删掉。

变成：

**两个候选失效现象**

第四张图还在后面。

许航收电脑的时候问：“你准备怎么讲？”

“就讲两套实现不一致。”

“日志那块呢？”

“也讲。”

“行。”

唐雨把白板上的纸一张张揭下来。

揭到第四张时，她停了一下。

最后还是一起夹进文件夹里。

第二天早上，许航收到她发来的一个表格。

两列。

左边写：**结构性失效链**。

右边写：**实现敏感性链**。

第二个现象放在左边。

第四个放在右边。

下面还有几行空着。

许航回：

> 这样可以。

隔了十分钟，唐雨问：

> 右边如果最后查出来只是实现差异，就停？

许航正在上课，没有回。

中午才看到。

他打了几个字，又删掉。

最后发：

> 先把检查做完。

唐雨只回了一个：

> 好。
