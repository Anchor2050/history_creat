# Pilot Chapter v3：招聘启事上的一天

> disposable adaptation-only braided revision。基于 v2，仅增加一处同学线回声：罗诚在问“能力怎么证明”时想到周野此前把技术可靠做成复现包；孙洁把讨论拉回罗诚自己的实际经历。其余保持删减版距离。

罗诚到行政楼的时候早了十二分钟。

电梯停在六层不动，他走楼梯上去。

孙洁办公室门开着。一个学生站在桌边，手里捏着两张表。

“我昨天交过电子版了。”

“这个还要纸质。”

“群里说电子版。”

孙洁往上翻聊天记录。

“昨天中午改过。下午四点前送来就行。”

“导师今天不在。”

“签字明早补，其他先交。”

学生又问了两句，走了。

另一个老师从里间出来，把一沓材料放到桌角。

“这几个学籍状态你再核一下。”

“十一点前给你。”

那人出去以后，孙洁才看罗诚。

“你早到了。”

“怕找不到楼。”

“坐吧，我还有一封邮件。”

罗诚坐到靠门的位置。

桌上两摞材料，一摞黄色便签，一摞蓝色便签。墙上贴着值班表，周末也有名字。

孙洁发完邮件，伸手：“给我看看。”

罗诚把招聘启事递过去。

“你想报这个？”

“嗯。学历、专业、年龄都够。”

“职责呢？”

罗诚笑了一下：“所以来找你。”

孙洁往下看。

“学生谈话，做过吗？”

“助教的时候有学生来找过我。”

“固定带班？”

“没有。”

“学生干部？”

“没有。”

“心理危机？”

“没有。”

罗诚手指在文件袋边上划了一下。

孙洁继续看：“活动组织。”

“学院活动帮过。报名统计、名单、签到。有一次临时少教室，我去联系过。”

“预算呢？”

“没碰过。”

“那就写你做过的。”

“会不会太碎？”

孙洁抬头：“这个工作很多事情本来就碎。”

下一项是材料审核。

“这个多。”罗诚说。

“什么材料？”

“报销、会议材料、论文附件。还有一次毕业去向表，我帮忙核过名字、学号和单位。”

“那就写这个。”

招聘启事里还有一句：具有较强的组织协调、沟通表达和学生工作能力。

罗诚指着那一行。

“这种怎么证明？”

“写事情。”

罗诚没马上记。

去年和同学吃饭的时候，周野说自己在整理一个最小复现包。技术岗至少还能把代码、环境和结果摊出来，让别人跑一遍。

“技术岗还能给人看个东西。”罗诚说，“我这个总不能也打个包。”

孙洁看了他一眼。

“那就别学技术岗。写你实际干过什么。”

罗诚低头在纸上记了一笔。

“博士优先呢？”

孙洁没有马上答。

“我是说，学生工作经历少一点，学历会不会补一点？”

“这个我不知道。”

“按你经验呢？”

“我只能告诉你这个岗位平时可能在干什么。”

“我没问内部线。”

“我知道。”

罗诚没再说。

孙洁拿笔划了几处：材料审核、值班、谈话、活动、跨部门协调。

“流程跟进，你有。记录，你有。直接学生工作偏少。值班你也没经验。”

罗诚盯着那几道线。

门口有人敲门。

刚才那个学生又回来了。

“老师，这个模板第二页也要导师签。”

孙洁把表接过来，看了一眼。

“这个是旧模板。”

她在电脑里找新文件，打印机没反应。

“又卡了。”

罗诚站起来：“我来？”

“不用。”

孙洁把纸盒拉出来，抽掉卡纸，重新打印。

“用这个。”

学生接过去：“群里没发这个。”

孙洁停了一下。

“我等会儿补。”

学生走后，她在电脑边贴了一张便签。

罗诚问：“你每天都这样？”

“差不多。”

“那你报的这个岗估计也会很碎。”

罗诚低头看那张纸。

“再看完吧。”

跨部门协调这一项，孙洁说他可以写博士期间实际做过的联系和跟进。

罗诚在纸上记：财务、学院办公室、会议材料。

“学生成长指导呢？”他问。

“你有就写。”

“我能讲课，能答疑。真让我说指导过谁成长，我不敢。”

“那就别写满。”

罗诚靠到椅背上。

“听着挺尴尬。”

“你自己来问细的。”

“嗯。”

孙洁把招聘启事推回去。

“你还是想报？”

罗诚把纸折了一下，又展开。

“投。”

“那就投。”

“你这个只是说我可以投吧？”

孙洁看了他一眼。

“对。”

罗诚笑了一下，很快又低头。

“我简历里活动组织那段，写‘协助学院完成’行不行？”

“你到底干了什么？”

“报名、名单、签到、临时找教室。”

“就写这些。”

“行。”

孙洁又低头去看刚才那沓学籍材料。

罗诚把文件袋夹到胳膊下面。

“今天谢谢。”

“嗯。门带一下。”

中午他没回宿舍，去了东门外的打印店。

店里一台电脑空着。

他把简历打开。

“具有较强组织协调能力”删掉。

“长期参与学院公共事务”也删掉。

活动经历改成：

> 报名统计、名单核对、现场签到；临时场地调整时联系学院办公室确认备用教室。

他看了一会儿，又往下改助教经历：

> 每周固定答疑；处理课程内容、选退课流程等个别咨询，涉及教务事项时引导学生向正式窗口确认。

还是没有“学生成长指导”。

他没补。

老板在后面问：“几页？”

“两页。”

“打吗？”

“等一下。”

罗诚把招聘启事放在键盘旁边，又对了一遍。

学生谈话。

活动组织。

材料审核。

值班。

跨部门协调。

文件名原来是：

`高校辅导员简历最终版`

他把“最终版”删掉，改成日期。

“好了。”

老板点打印。

第一页出来的时候中间有一道黑线。

老板拿起来看了看。

“硒鼓快不行了。我换台机器。”

“行。”

罗诚站在旁边等。
