# 开篇入口 A v1：别人能不能跑出来

> disposable adaptation-only prose。历史锚点：2027 年 7 月周野通过国企技术筛查并进入最终面试；筛查中确实被问到别人如何复跑、结果如何核验、异常如何记录，他的复现包成为解释工作方式的证据。面试房间、面试官人数、现场对白、动作细节为改编层虚构。

“这个东西如果你不在，别人能跑出来吗？”

周野抬了一下头。

坐在中间的男人把他的材料翻到最后一页。桌上有三份打印出来的简历，其中一份边角已经卷了。

“能。”周野说。

“你确定？”

“我换过机器。”

“我说别人。”

周野停了两秒。

会议室空调开得很低。他进来以前在楼下等了四十分钟，衬衫后背原来有一点汗，现在已经干了。

他把电脑往前推了推。

“那您从这个开始。”

屏幕上是一个文件夹。

`README`

`env`

`input`

`output_expected`

`failure_log`

旁边那个一直没说话的面试官往前坐了一点。

“失败记录是什么？”

“跑不通的时候记的。”

“跑不通也放进去？”

“嗯。”

中间的人笑了一下。

“你们学校现在都这么做？”

“不是。”

“那你为什么做？”

周野说：“之前有一次我自己三个月以后都不知道为什么改过。”

“所以？”

“以后就记了。”

对方没有马上接。

桌边放着一只纸杯，杯口已经被捏扁了一点。另一个面试官低头看简历。

“统计学博士。”

“对。”

“论文呢？”

周野看过去。

“目前没有正式发表。”

“投过吗？”

“有在做的，没形成能写进这里的结果。”

那人用笔点了两下简历上的空白处。

“那你这个——”

他又看向电脑。

“算项目？”

“算一个工作样本吧。”

“谁让你做的？”

“我自己整理的。”

“为了找工作？”

“后来是。”

中间的人抬头：“后来？”

周野说：“一开始是因为我自己跑不回去了。”

会议室里安静了一下。

门外有人经过，说话声隔着玻璃传进来。面试官把最后一页材料翻回去。

“行，那假设我现在拿走。”

他伸手点了点屏幕。

“第一步做什么？”

“先看环境文件。”

“我不看。”

周野愣了一下。

“为什么？”

“我就直接点主程序。”

“那可能会报错。”

“为什么？”

“缺包，或者版本不一样。”

“那你这个不是不能直接跑？”

周野看了他一眼。

“所以 README 第一行写了先装环境。”

旁边的人笑了一声。

中间的男人也没生气。

“用户不看说明怎么办？”

“那就看报错够不够清楚。”

“够吗？”

“现在还不完全够。”

“哪里不够？”

周野把 `failure_log` 打开。

最下面有一条：

> 新环境直接运行主脚本：包缺失提示不完整。

日期是两周前。

“这个还没改。”他说。

“为什么不改完再来？”

“来不及。”

“你不是说你很重视可靠？”

这句话出来以后，周野没有马上答。

他不知道对方是从哪里看到“可靠”两个字的。也许是申请表，也许是前一轮技术题后面那段自述。

中间的人把纸往旁边挪了挪。

周野说：“没改完就写没改完。”

对方看了他几秒。

“好。”

他又问：“结果怎么核？”

周野打开 `output_expected`。

“不是要求每一位小数都一样。这里有一组主统计量，还有两个诊断值。超过这个范围就要查。”

“范围谁定的？”

“我按重复运行的波动定的。”

“多少次？”

“二十次。”

“二十次够吗？”

“这个例子够不够，我不敢说。”

“那你敢拿来做样本？”

“敢。”

“为什么？”

“因为它是让您看我怎么做事，不是证明这个数有理论保证。”

旁边的人把笔停住了。

中间的男人往后靠。

“你找的这个岗位，日常不是做论文。”

“我知道。”

“有时候是别人给你一套跑了两年的东西，你接过来，文档不全，人也可能已经走了。”

“嗯。”

“还有时候是你交出去，半年以后别人回来问为什么跟你当时不一样。”

周野点头。

“那你最怕哪一种？”

他本来想说都不怕。

话到嘴边停了。

“第二种。”

“为什么？”

“第一种至少一开始就知道有问题。第二种可能大家都觉得没问题。”

这次没人笑。

面试官低头在纸上写了什么。

周野看不清。

他忽然意识到自己两只手一直放在桌边，右手拇指在刮左手食指的指甲。

他把手放到腿上。

“还有一个问题。”

旁边那个面试官第一次主动问。

“你这个包，如果交给一个不懂统计的人，他能不能判断结果有问题？”

“不能完全判断。”

“那有什么用？”

“他至少能知道什么时候不要继续往下用。”

“靠什么？”

“两个检查值，还有失败条件。”

“如果检查值没报错，但结论还是错的呢？”

周野抿了一下嘴。

“那这套东西挡不住。”

“所以可靠在哪？”

周野没有看电脑。

过了一会儿他说：“只能少错一部分。”

空调出风口响了一阵。

中间的人把材料合上。

“行。今天先到这儿。”

周野愣了一下，才把电脑转回来。

“好。”

“外面有人带你出去。”

他把电源线拔掉。插头卡在桌腿后面，拉了一下没出来。

旁边那个面试官弯腰帮他拨开椅子。

“在下面。”

“谢谢。”

周野把线收进包里。

走到门口的时候，中间的人忽然问：

“你简历上为什么没把这个放前面？”

周野回头。

“我不知道算不算成果。”

“我也没说算成果。”

“嗯。”

门已经开了。

周野说：“所以放后面了。”

他出去以后，走廊里还有三个人在等。

一个人在背面试题，声音很小。另一个人靠墙看手机。

带路的工作人员把访客牌收回去，说：“电梯右边。”

周野按了下行。

电梯从十二楼往下跳。

十一。

十。

手机在裤兜里震了一下。

他以为是许航。

拿出来，是一条银行短信。

余额变动十二块六。

早上打车的平台补扣。

电梯到了。

他把手机塞回去。

一楼大厅有人拖地，门口的地垫卷起一个角。周野跨过去，站到外面。

太阳很亮。

他走到公交站，才给许航发了一句：

> 问得挺细。

许航过了半个小时才回：

> 哪部分？

周野看着那三个字，没回。

两天后，邮箱里多了一封新邮件。

标题很短：

**最终面试通知。**
