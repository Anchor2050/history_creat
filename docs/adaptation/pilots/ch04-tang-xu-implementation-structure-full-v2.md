# Full Pilot：换一种实现以后 v2

> disposable adaptation-only full chapter。v2 仅做删减与降调：减少主题性对白、减少提前完成弧光的“停止”意识，不新增历史事实。

唐雨把四张图打印出来的时候，第四张颜色偏了一点。

打印机把蓝色打成了灰紫。

她重新打了一份，还是一样。

两份都拿走了。

许航到的时候，图已经贴在白板上。第一排是原来的实现，第二排是她前一天换的实现。

“先看第二个和第四个。”

许航把包放下。

“别的呢？”

“先不管。”

第二个现象两排都在。

第四个不是。

许航站近了一点。

“你换了什么？”

“中间那一步。原来自己写的，下面这版换成现成包。”

“参数一样？”

“能对的都对了。”

许航坐下来翻代码。

“默认容差多少？”

唐雨打开帮助页。

看见数字以后，她把窗口往旁边拖了一点。

“比我那版松。”

“嗯。”

“但第二个没变。”

“先看完。”

许航继续往下。

日志到后面少了一截退出状态。

“这几次呢？”

“机器断过，手动重跑的。”

“中间没记？”

“没有。”

许航点了一下头。

唐雨说：“你别点头。”

“好。”

门外有人问有没有订书机。

唐雨指了下窗台。

门没关严，走廊里打印机响了一阵。

她起身去关门。

回来以后，还是站到白板前。

“第二个换实现也在。”

“目前是。”

“那它至少比第四个稳。”

许航没接，重新把两个版本放到一块。

输入一样。

初始化一样。

截断的位置不一样。

停止条件也不一样。

随机种子设置的位置，她前一天已经改过，但只重跑了两组。

许航问：“全矩阵呢？”

“没跑完。”

“那先把能对齐的对齐。”

唐雨把第四张纸揭下来，放在桌边。

“这个我本来想和第二个一起讲。”

“今天还讲？”

“讲观察。”

“行。”

她看了他一眼。

“你这个‘行’很敷衍。”

许航已经在看下一段代码。

“我在看这个。”

两个人继续往下对。

二十多分钟没有找到新的东西。

许航去接水，回来时唐雨还停在同一页。

“这里。”他说。

现成包连续两次满足条件就停，她原来的实现要三次。

唐雨说：“差一次能差这么多？”

“跑一下。”

“全的跑不完。”

“那跑小的。”

她改了样本量。

程序开始跑。

中间两个人去楼下买饭。

食堂后排只剩几个窗口。

唐雨点了碗面，许航拿了盒饭。

坐下以后，先说的是下午谁要用会议室。

吃到一半，唐雨说：“第四个最开始最明显。”

许航抬头。

“嗯。”

“如果是真的，后面会省很多事。”

许航夹了一口菜。

“先把今天这个跑完。”

唐雨没再说。

回去以后，小规模结果已经出来。

停止条件对齐后，第四个现象比原来强一点，但还是远弱于第一套实现。

第二个变化不大。

唐雨把两张图叠在一起。

“所以第四个还是吃实现。”

“看起来是。”

“第二个单独留。”

“可以。”

“第四个再查。”

“嗯。”

两点四十多。

唐雨把下午汇报的文件打开。

第一页原来写着：

**两个稳定失效现象**

她选中“稳定”两个字。

停了几秒，改成：

**两个失效现象：初步检查**

第四张图还在后面。

许航收电脑。

“日志那几次补一下。”

“晚上补。”

“还有参数表。”

“知道。”

他走以后，唐雨把白板上的纸一张张取下来。

第四张和第二张分开放进两个透明文件夹。

第二天上午，许航收到她发来的表格。

左边写：

**结构检查**

右边写：

**实现检查**

第二个现象在左边。

第四个在右边。

下面各留了几行空格。

许航回：

> 收到。

唐雨没有再发消息。
