# Alpha v2 scene replay 01

本轮目标不是补剧情，而是检验已经稳定的历史骨架能不能长成场景。以下所有决定性事实均来自 `alpha_history_2035_v2.py`；新增内容只允许属于场景表达：动作、停顿、环境纹理、非决定性的普通物件与有限视角。

## 场景选择

### S1 — 2032-12-09：林静向陈岚承认“我怕的是以后没得选”
功能：把 2027 年以来的比较伤口从收入/成功转成“能不能行使选择”。

不能写成：两人彻底和解；陈岚洞悉林静全部动机；林静突然获得行动勇气。

适合反复的普通物件：租约续签提醒、旧招聘页面截图。它们只能承载意义变化，不能凭空变成决定性证据。

### S2 — 2033-05-12：许航拒绝给不可复核的数据来源背书
功能：第一次让“善”产生持久的人际成本。真正的张力来自两个合理目标无法同时满足：林静要保住窗口，许航要保住可复核性。

不能写成：许航冷酷；林静不讲原则；任何一方在当场知道几年后的后果。

### S3 — 2034-11-15：陈岚重开更小的带薪训练批次
功能：善意失败后的第二次尝试。她恢复了部分时间，所以不能继续靠疲惫制造意义；张力转到“还敢不敢重新承诺”。

物件：旧预算表里那一行“暂停新增”。新学员看到的是训练材料，陈岚看到的是自己以前说过的话。

### S4 — 2035-12-06：三条人生线在同一场培训里错开
功能：完成长期回声但拒绝团圆。陈岚使用许航的材料；林静只参加前半场；许航因另一场付费审查没有来。

不能写成：命运安排他们错过；三个人隔空同时想到同一句话；叙述者替他们宣布“这就是时代”。

# S2 全场景试写：签字

林静把文件又往上滚了一点。

屏幕右侧那一栏空着，只有“数据来源复核人”后面一条灰线。她盯了几秒，把鼠标移开。

许航那边没有声音。

“我不是让你确认数据是真的。”林静说，“我只需要你确认，这个来源在项目里出现过。就这一层。”

耳机里传来一次很轻的敲键盘声。

“出现过和能复核，不是一回事。”

“我知道。”

她说得太快，自己也听出来了。

窗口右下角跳了一下。离合作方下一场会还有二十七分钟。她把提醒关掉。

“现在他们卡的就是这个。”她说，“前面都已经走完了。如果这个签不下来，后面要重新排。”

许航没有接“重新排”这三个字。

林静又把文件往下滚。那一页其实已经看过很多遍了，表格里每个格子的宽度她都快记住了。她只是需要有东西跟着手指动。

“你去年不也说过，现实项目不可能每一步都做到理想状态吗？”

“说过。”

“那你现在——”

她停住。

许航那边终于有了一点背景声，像椅子腿碰了一下地面。

“我可以把我核过的部分列出来。”他说，“也可以写哪些地方现在核不了。这个我今天能给你。”

“我要的不是这个。”

“我知道。”

这次轮到她那边安静。

林静看见自己的名字在文件第一页最上面。下面是项目名，再下面是日期。已经晚了两个月的日期。

“你就不能先把这个窗口过了？”

许航没有马上回答。

林静忽然觉得这句话听起来像另一种话。像以前他们一起改东西改到半夜，她把一处没想清楚的地方先标黄，说先过去，明天再回来。那时候“先过去”只是文档里的动作。

现在灰线还空着。

“这个东西一旦我签了，”许航说，“以后别人问你来源怎么核的，你会说我看过。你不会说错，因为我的名字就在上面。”

“我可以解释。”

“你当然可以解释。”

他的声音没有提高。

“问题是别人为什么要先相信你的解释。”

林静把鼠标从灰线上挪开。

离会议还有二十三分钟。

“行。”她说。

许航像是还想说什么。她没等。

“你把你能核的发我吧。”

“好。”

“今天。”

“今天。”

她把通话关掉。

房间里没有什么变化。空调还在响，桌上的水已经凉了。屏幕上那条灰线也没有因为他们刚才说了十几分钟而变长一点。

林静重新打开合作方的聊天窗口。

她先打了“数据来源复核需要补充材料”。

删掉。

又打：“我们需要调整一下时间。”

这一次她没有立刻发。

## 事实审阅

场景保持了以下硬事实：
- 林静需要不可复核来源的背书；
- 许航拒绝签字，也拒绝用模糊口头背书替代；
- 他愿意提供自己确实核过的部分；这不改变后续历史，只是对拒绝边界的表达；
- 林静面临项目延期与合作窗口压力；
- 当场没有任何人知道关系会中断多久。

需要继续警惕：
- “合作方下一场会还有二十七分钟”属于场景计时，不能在后续被追认为一个新增制度期限；
- “去年说过现实项目不可能每一步理想”属于普通共同记忆，只能用于人物语气，不可据此建立新的历史承诺。

## 文学审阅

### 有效处
1. 冲突不靠吵架。两人一直在理解对方，因此拒绝更疼。
2. “先过去”从共同工作的普通措辞变成证据责任的边界，形成轻微的意义回声。
3. 灰色签字线是普通物件，没有被抒情化，却能承载压力。
4. 许航没有被写成原则机器：他给出自己可以承担的那一部分工作。
5. 结尾停在林静没有发送的延期消息上，没有替她总结道理。

### 仍然偏人工的地方
1. “问题是别人为什么要先相信你的解释”略像主题句，下一版可考虑再口语一点。
2. 二十七分钟/二十三分钟的倒计时有效，但有轻微影视剧感。需要和更普通、更松散的版本比较。
3. 当前场景仍然太干净：真实工作沟通通常会有跑题、重复、确认文件版本等摩擦。下一版可增加一处无意义但真实的操作障碍，前提是不改变事实。

## S2 变体要求
下一轮至少生成两个版本：
- **V2a 更普通**：去掉明确倒计时，让压力来自对方已经催过、林静不停切窗口；
- **V2b 更伤关系但更克制**：保留对话内容，删去任何漂亮回声，仅靠双方越来越正式的称呼和句子长度变化表现关系改变。

如果更朴素的版本反而更有力量，应删除当前版本中“先过去”的回声。美不能因为已经被设计出来就获得保留权。

# S4 场景骨架：错开的下午

视角暂定陈岚，避免三人全知切换。

已知事实顺序：
1. 陈岚主持/参与小规模带薪训练；
2. 训练材料包含许航整理过的失败/验证内容；
3. 林静参加前半场，因自己的工作离开；
4. 许航同日承担另一场付费审查，没有出席；
5. 无重逢、无主题总结。

可工作的张力：
- 陈岚曾经因为预算砍掉名额，如今重新面对学员，不敢把“这次能持续”说得太满；
- 她使用许航材料时知道材料的来路，却不知道林静与许航现在到底算什么关系；
- 林静离场是普通工作安排，不应写成逃避；
- 许航缺席甚至说明一件正面的事：他的验证劳动终于有人付钱。但这份正面转换同时取消了一个可能发生的重逢。

这使结尾具备真正的多义性：一个制度改善可以在同一天制造一个人的收入、另一个人的训练机会，以及三个人没有见面的事实。无需判断哪一个更重要。
